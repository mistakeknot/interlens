## Severity Calibration

- **P0**: The webhook endpoint goes down silently (no error, just dropped events) and the system continues to trust dead-reckoning (assuming no remote changes) for the full 5-minute poll interval — during this window, multiple remote file changes are missed, and when the poll finally detects divergence, the accumulated drift exceeds what three-way merge can resolve cleanly, producing conflicts that would not have occurred if changes had been processed incrementally as they arrived
  - When: When webhook failure is not independently detectable and the system has no heartbeat or liveness check for the webhook channel, relying entirely on the poll interval to discover missed events
- **P1**: A push webhook event and a poll reconciliation both detect the same remote file change within a short window — the webhook triggers an immediate sync, then the poll runs and detects the same change (because the tree SHA was captured before the webhook-triggered sync completed), causing the system to process the same change twice, either creating a duplicate local write or detecting a false conflict between the two representations of the same change
  - When: When the poll's tree-SHA snapshot is captured at the start of the poll cycle and not refreshed after webhook-triggered syncs complete within the same cycle, and the deduplication logic does not correlate webhook events with poll-detected changes
- **P2**: The system treats webhook silence as 'no remote changes' without distinguishing between 'no changes happened' and 'changes happened but the webhook failed to deliver' — the navigation equivalent of interpreting clear skies (no star signal) as 'we are on course' rather than 'we cannot verify our course'
  - When: When the absence of webhook events within a poll interval is interpreted as confirmation of no remote changes rather than as absence of evidence, and the poll is the only mechanism that can detect missed webhook events

When in doubt: describe the failure scenario. If it wakes someone at 3 AM, it is P0/P1. If it degrades quality over weeks, it is P2.
