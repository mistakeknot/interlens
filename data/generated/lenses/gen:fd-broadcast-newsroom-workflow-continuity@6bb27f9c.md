## Severity Calibration

- **P0**: Swift app caches shotlist.json in memory after first load and does not watch for file changes.
  - When: A render triggered from the UI completes and updates shotlist.json on disk, but the timeline strip still shows old state — user re-dispatches shots already rendered, corrupting the output directory.
- **P1**: No explicit dependency graph between surfaces — script export is not a prerequisite check before video render dispatch.
  - When: User dispatches ComfyUI render with a stale or absent script.md, producing shots that don't match the current script revision.
- **P2**: Research dialogue transcripts are written to disk asynchronously with no conflict detection.
  - When: Two rapid dialogue turns both attempt to append to the same corpus file; one write silently wins and the other is lost.

When in doubt: describe the failure scenario. If it wakes someone at 3 AM, it is P0/P1. If it degrades quality over weeks, it is P2.
