## Severity Calibration

- **P1**: The BYPASS trigger writes factory-paused.json but the interspect write path is on the same error return branch — a recoverable interspect error causes the entire BYPASS trigger to roll back, deleting factory-paused.json, so the halt is silently voided
  - When: When the interspect write and the filesystem write share an error handling path and the design intent (file is the authority, interspect is secondary) is not encoded in the error handling — interspect failure should be logged and tolerated, not used to abort the halt
- **P1**: The resume command checks for active Tier 2 CONSTRAIN signals as a stub (no-op per brainstorm R4) — when Tier 2 is implemented in F6, the stub is forgotten and resume allows restart into a factory that still has active constraints, because the stub never fails and no test exercises the CONSTRAIN-active gate
  - When: When the CONSTRAIN check is written as a no-op comment rather than as an interface with a TODO that fails tests until implemented, making it invisible to the developer who ships Tier 2 six months later
- **P2**: The resume command deletes factory-paused.json before confirming that the ratchet_state reset transaction committed — a crash between the SQLite commit and the file deletion leaves halt signaled with all domains at supervised, but a crash after file deletion and before transaction commit leaves halt cleared with domains at their pre-halt autonomous tier
  - When: When the ordering in D3 (clear interspect record → reset ratchet tx → delete file) is implemented but not tested with crash injection between the SQLite commit and file deletion
