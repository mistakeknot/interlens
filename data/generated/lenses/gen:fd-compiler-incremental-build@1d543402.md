## Severity Calibration

- **P1**: Each /loop tick burns full re-orientation cost (git status, bd list, recent commits) even when nothing has changed since the last tick
  - When: 20 ticks per hour × full re-orientation cost = unnecessary token spend in idle loops
- **P2**: /clavain:status regenerates all sections on every invocation even though only one bead status changed since the last call
  - When: Per-invocation cost grows with project size instead of with delta size
- **P2**: Generated artifacts (roadmaps, vision docs) lack a content-hash header that would let downstream readers detect staleness
  - When: Drift detection requires manual /interpath:propagate runs

When in doubt: describe the failure scenario. If it wakes someone at 3 AM, it is P0/P1. If it degrades quality over weeks, it is P2.
