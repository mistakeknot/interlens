## Severity Calibration

- **P0**: The orchestrator lands commit B using a PASS produced for commit C under criteria frozen from plan A, so apparently corroborated evidence supports neither the landed state nor the actual goal claim.
  - When: Artifact identity and assurance provenance are not jointly bound and checked at landing.
- **P1**: A partial retry or concurrent mutation changes the tested state, and the pilot records the resulting validator disagreement as an independent unique catch attributable to Opus.
  - When: Attempt causality and counterfactual classification cannot distinguish added validator information from state or environment drift.
- **P2**: A result names the plan hash and commit but omits the oracle version or fault model, forcing the orchestrator to reopen artifacts before deciding whether the verdict applies.
  - When: The handoff is operationally traceable but not an auditable assurance claim.

When in doubt: describe the failure scenario. If it wakes someone at 3 AM, it is P0/P1. If it degrades quality over weeks, it is P2.
