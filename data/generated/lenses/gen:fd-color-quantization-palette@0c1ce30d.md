  - When: Occurs when the palette naming convention is not enforced by a constant enum in the TypeScript implementation, allowing different code paths to use different serialization conventions.

## Decision Lens

Color quantization is correct when the LLM receiving the quantized output makes the same decisions it would make with the original colors. A quantization that maps Solarized yellow (#b58900) to 'yellow' and maps Solarized base1 (#93a1a1) to 'cyan' is semantically wrong even if the nearest-neighbor distance is small. The error criterion is not perceptual fidelity but task decision fidelity — does the LLM still know that a test failed, a menu item is selected, a file is staged?
