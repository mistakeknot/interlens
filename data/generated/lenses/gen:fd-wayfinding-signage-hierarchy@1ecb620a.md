## Task Context

Wayfinding research quantifies how much information a navigator can absorb at each decision point. LLM agents navigating terminal UIs face the same cognitive budget.

## Review Approach

### 1. Progressive disclosure hierarchy

- Progressive disclosure hierarchy — wayfinding shows broad direction first, then specific route, then final destination. Terminal state could be disclosed progressively.

### 2. Decision-point signage

- Decision-point signage — signs appear at decision points, not continuously. Terminal state updates should focus on where the agent needs to make a choice.

### 3. Landmark-based navigation

- Landmark-based navigation — wayfinding uses landmarks not coordinates. Terminal navigation could use landmarks (prompt, error block, menu).

### 4. Information overload thresholds

- Information overload thresholds — wayfinding research shows maximum useful sign density before confusion. Maps to: maximum useful terminal state detail before LLM confusion.

## Severity Calibration

- **P1**: All information at same priority level
  - When: Terminal header, content, status bar all encoded at same detail — no hierarchy
- **P2**: No landmark system
  - When: Agent must parse entire screen to find where it should look

When in doubt: describe the failure scenario. If it wakes someone at 3 AM, it is P0/P1. If it degrades quality over weeks, it is P2.
