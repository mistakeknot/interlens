  - When: P0 if branch A and B are not isolated to independent queues/buffers with independent lifecycles; downgrade to P2 if branch A has a dedicated, higher-QoS path that is structurally immune to branch B's backlog and this isolation is tested.
- **P1**: privacy-flow.json and sink-registry.json are copied into the app bundle at build time but nothing asserts the copy is byte-identical to shared/pipeline-contract/ (unlike consent-copy.txt, which has a byte-identical unit test), so the app can ship a stale flow table that has drifted sharp from the canonical master and makes different flow decisions than the contract.
