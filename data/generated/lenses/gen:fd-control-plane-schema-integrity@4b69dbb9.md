## Severity Calibration

- **P1**: Operator typos intent_status as 'in-progress' (hyphen) instead of 'in_progress' (underscore) in a control-plane JSON; no error is raised, the session silently never generates missing_runtime drift
  - When: A real runtime gap goes undetected because the intent_status check uses exact string equality with no normalization or validation
- **P1**: Session.desired_runtime_id is populated with a control-plane session ID but the reconciler looks it up in runtime_by_id keyed on runtime_id — these namespaces are different, producing a permanent silent miss
  - When: The fallback lookup in reconciler.py line 24 never resolves because the ID formats are incompatible
- **P2**: A project is removed from the control plane but sessions referencing its project_id remain; orphaned sessions generate drift records with project_id pointing to a non-existent project
  - When: Public projection skips orphaned sessions silently; operator has no visibility that the control-plane state is inconsistent

When in doubt: describe the failure scenario. If it wakes someone at 3 AM, it is P0/P1. If it degrades quality over weeks, it is P2.
