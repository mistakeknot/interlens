## Task Context

Tuivision is a TUI testing/automation MCP server that gives AI agents visual access to terminal applications. Current modes: get_screen text (~200-400 tokens, no style), get_screenshot png (~1600 vision tokens), get_screenshot svg (~2000-8000 tokens, contains text+style but verbose). The goal is a new representation that captures text + task-relevant visual semantics at significantly fewer tokens than PNG/SVG while preserving the semantic information that plain text loses. Ideas already proposed include local OCR on PNGs and optimized SVG stripping.

## Severity Calibration

- **P0**: The optimized representation strips color information from a test runner output, causing the LLM to miss that 3 tests failed (red) and report all-pass, executing a destructive deploy.
  - When: Occurs when color is the sole differentiator between pass/fail status and the text content is identical (e.g., both show test names without explicit PASS/FAIL labels).
- **P1**: The encoding preserves all 256 color values as distinct tokens when the LLM's actual discriminative ability tops out at ~16 named colors, wasting 40%+ of the attribute token budget on precision the model cannot use.
  - When: Triggered when truecolor or xterm-256 palettes are encoded numerically rather than quantized to named color buckets.
- **P2**: Cursor position is omitted from the representation, causing the agent to send keystrokes to the wrong widget because it cannot determine which input field has focus.
  - When: Occurs in multi-pane TUI applications where Tab/Shift-Tab navigation changes focus without visible text changes.

When in doubt: describe the failure scenario. If it wakes someone at 3 AM, it is P0/P1. If it degrades quality over weeks, it is P2.

## Decision Lens

Every token spent encoding terminal attributes must justify itself by improving the LLM's ability to take the correct next action. A color that distinguishes an error from a success message is high-signal; a color that brands a UI panel border is zero-signal. Flags whenever a representation encodes decoration at the same fidelity as semantics. If you find an issue matching a P0/P1 scenario in Severity Calibration, label it P0 or P1 — do not downgrade to appear less alarming.
