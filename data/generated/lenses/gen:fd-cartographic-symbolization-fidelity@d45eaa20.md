## Review Approach

### 1. Symbol differentiation budget

- Symbol differentiation budget: topographic maps use a strict symbol library — braille patterns, half-block fills, and box-drawing characters each occupy distinct visual frequency bands that must not collide

### 2. Figure-ground separation

- Figure-ground separation: 24-bit color enables true chroma/lightness separation between foreground entities and background terrain — cartographic practice demands >3:1 luminance contrast for legibility

### 3. Multi-scale consistency

- Multi-scale consistency: kitty/sixel image insets vs. ASCII surroundings create a scale discontinuity — the same information at two visual resolutions must not contradict each other

### 4. Overprinting hazards

- Overprinting hazards: layering braille unicode over colored background cells replicates the cartographic overprint problem — ink-on-ink opacity must be managed or the symbol disappears

### 5. Visual hierarchy depth

- Visual hierarchy depth: professional topo sheets carry 6-8 separable visual layers (hydrography, contours, vegetation, built) — ASCII rendering needs explicit z-order assignment for each rendering mode

## Severity Calibration
