## Severity Calibration

- **P1**: When GPS is unavailable for the opening minutes, geohash5 is back-filled from the first later fix and stamped onto earlier frames, so the record presents reckoned/assumed position as if it were a measured fix — a downstream k-anonymity or lineage consumer cannot distinguish measured from inferred location.
  - When: P1 if there is no explicit not-yet-fixed marker for pre-first-fix intervals; downgrade to P2 if early intervals are honestly flagged as position-unknown and only coarsened once a real fix lands.
- **P1**: A thermal shed of branch B or a storage-triggered pause creates an audio gap that is not written as its own explained session event, so it is indistinguishable at analysis time from a user-initiated pause — the 'zero unplanned gaps' acceptance metric can be passed by mislabeling an unplanned gap as planned.
  - When: P1 if any gap-producing cause lacks a dedicated logged event type distinct from user-pause; downgrade to P3 if every gap cause emits a distinct, testable event and the drop count is computed from causes, not from silence.
- **P2**: The session epoch anchoring wall-clock to the monotonic clock is recorded once at start but never re-checked; if the wall clock is adjusted mid-session (NTP step, timezone/DST change), later wall-clock timestamps silently disagree with the monotonic timeline and no event records the discontinuity.
  - When: P2 if there is no clock-adjustment detection or event; downgrade to P3 if clock steps are detected and logged as an explained discontinuity.

When in doubt: describe the failure scenario. If it wakes someone at 3 AM, it is P0/P1. If it degrades quality over weeks, it is P2.

- Insist that every gap has a named, logged cause; treat any silence that could be either planned or unplanned as a defect.
- Distinguish measured from inferred data everywhere position or time is recorded — the defect is confusion between the two, not the inference itself.
- Check that the log survives a mid-voyage crash as a readable record, not just that it's correct on clean shutdown.

## Decision Lens
