  - When: Applies whenever the render layer has no separate code path for 'unmeasurable' vs 'measured zero' vs 'unresolvable.'
- **P1**: The admin write path accepts and saves a URL string with no reachability or format check beyond HTML's type="url" validation, which passes a typo'd, nonexistent repo URL just as happily as the real one; the mistake is only discoverable later by someone cross-referencing the public metric against expectations, by which point the original editor has moved on and the provenance of the error is lost.
  - When: Applies to any variant whose admin form ships without a resolve/preview step at save time.
- **P2**: The public page renders the days-touched number but not the resolved repository identity it was computed from, so a reader who suspects a number is wrong has no way to verify it without admin access to the content source — auditability exists in principle (the data is in the repo) but not in practice (it's not exposed where the claim is made).
  - When: Applies whenever the project page template omits the resolved repo reference next to the metric it produced.
