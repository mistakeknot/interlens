## Task Context

Shadow Work is a Rust/Tauri geopolitical simulation. The emergence/ pillar contains PressureStore (per-country HashMap<PressureType, f32>), EmergenceConfig (CascadeConfig with neighbor graphs), and a tick pipeline where tick_simulation() calls pressure decay via tick_all_scaled(DAILY_SCALE). ## Review Approach

### 1. ComputeStore parallel to PressureStore
- Verify the compute module owns a ComputeStore parallel to PressureStore — per-country per-region fields (fab_capacity_nm, gpu_stockpile_units, data_center_gw, export_control_tier) — and that its state is serde-serializable and skips runtime-only caches with #[serde(skip)] like PressureStore does

### 2. Signal emission pattern
- Check whether compute signals are emitted as pressure amplification deltas (like collect_pressure_amplification() in issues/store/effects.rs) or as a separate signal bus — verify the chosen pattern doesn't require callers in other modules to import compute internals directly

### 3. Tick integration point
- Audit the tick integration point: compute tick should slot into tick_simulation() as a peer call (not inside pressure decay or agent action loops) and accept a DAILY_SCALE argument consistent with the existing daily cadence

### 4. PressureType extension
- Confirm CountryPressures is extended with a ComputePressure variant in PressureType::ALL or that a new PressureType enum arm is added — verify PressureType::ALL iteration still initializes the new arm in CountryPressures::new()

### 5. CascadeConfig sufficiency
- Assess whether CascadeConfig's neighbor graph (trade/alliance/border) is sufficient to model semiconductor supply chain contagion — Taiwan-to-South-Korea cascades are trade-type but TSMC concentration is a single-country production constraint, not a neighbor relationship

### 6. Default impl for restart
- Verify the compute module has a Default impl usable by SimulationTicker::default() so restart (full replacement) clears compute state without special-casing
