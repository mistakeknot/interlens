## Severity Calibration

- **P1**: Operator runs the audition, the three patches sound 'somewhat different', and declares M1 passed — but the difference is entirely due to different MIDI input clips, not the patch mutations. The audition uses three different stems accidentally.
  - When: PRD does not require the same source MIDI for all three renders, or does not specify how the operator verifies same-source.
- **P1**: All three patches produce non-zero mutation counts, audio is distinguishable, but the differences are random variation from a silent RNG bug rather than deterministic patch behavior. Operator passes M1, but re-running produces different results.
  - When: Audition protocol has no determinism check — it does not require the operator to render each patch twice and verify byte-identical audio before making the perceptual judgment.
- **P2**: The subtle patch produces changes that are audible to a trained listener but not to the operator (who is not a Hindustani musician). The audition passes 'straight' vs 'orthodox' but conflates 'subtle' with 'straight', missing a real implementation difference.
  - When: No reference material or listener qualification is specified for the audition. The test validity depends on operator musical literacy that the PRD does not audit.

When in doubt: describe the failure scenario. If it wakes someone at 3 AM, it is P0/P1. If it degrades quality over weeks, it is P2.
