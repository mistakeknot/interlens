## Severity Calibration

- **P0**: The recommended variant stores only names — URLs, or canonicalized org/name tokens — with nothing derived from the repositories themselves, so a rename, transfer or reclaimed name inside the measurement window leaves a mapping that still resolves, still parses, and now points at different material. The item reports a plausible days-touched figure computed from the wrong substance, and no check anywhere in the system can contradict it.
  - When: Applies when every stored value is a label and no part of the record is derived from repository content.
- **P0**: A repository is archived, made private or deleted, and the only available response under the chosen variant is to edit the mapping to point somewhere else or to leave it pointing at nothing. Either way the published record shows no evidence that a substitution or a loss occurred, so a stand-in repository's activity is reported as the item's own with the same confidence as an unbroken mapping.
  - When: Applies to any variant with no way to mark an entry as a declared substitute or as knowingly unavailable.
- **P1**: The mapping is accepted at the counter on syntax alone — a valid URL for a repository that does not exist, or exists under a different owner — and every downstream stage treats it as authenticated material. The error becomes undetectable at the first aggregation, because a repository that resolves to no checkout is indistinguishable in the day-set from one that had no qualifying commits.
  - When: Applies when no stage between the admin form and the published number reads the actual repository.
- **P1**: The design is judged solely on mapping correctness, so the case where a correct mapping still reads zero — work committed under an identity outside the assay's marker set, or a repository present on neither machine — is never considered, and the recommendation claims a guarantee against silent zeros that it does not provide.
  - When: Applies when the review scopes the failure mode to wrong mappings only.
- **P2**: An array-capable variant is recommended without a rule about what may go in the array, so an item accumulates a genuine repository plus a loosely related one and reports a larger figure than either alone. The mixture is undetectable after aggregation, and the public page shows a number with no account of what went into it.
  - When: Applies to A, B and C where multiplicity is permitted without an admission standard.

When in doubt: describe the failure scenario. If it wakes someone at 3 AM, it is P0/P1. If it degrades quality over weeks, it is P2.
