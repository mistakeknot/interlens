## Severity Calibration

- **P0**: install.sh appends a duplicate `mcp_servers:` config block on re-run
  - When: Hermes config format rejects duplicate keys silently, causing auraken-lens to load from one block and be shadowed by another — the user sees the skill installed but lens_select never returns results
- **P1**: Version gate passes an incompatible Hermes version
  - When: `hermes --version` output format changes between releases (e.g., `Hermes 2026.4.0-rc1` vs `2026.4.0`) and the semver parse regex matches the wrong substring, installing against an unsupported version
- **P2**: install.sh writes the MCP config snippet to the wrong location on macOS
  - When: Profile path enumeration assumes Linux `~/.hermes-*/profiles/` but macOS Hermes uses a different default config dir — install appears to succeed but Hermes never loads the MCP

When in doubt: describe the failure scenario. If it wakes someone at 3 AM, it is P0/P1. If it degrades quality over weeks, it is P2.
