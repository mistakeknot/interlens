### 2. Perceptual lossless vs. mathematically lossless

- Perceptual lossless vs. mathematically lossless — acceptable degradation that doesn't change clinical decisions

### 3. DICOM metadata as companion channel

- DICOM metadata as companion channel — structured metadata travels alongside the image, not embedded in it

### 4. Progressive resolution

- Progressive resolution — send a low-res version first, enhance on demand

### 5. Windowing and level

- Windowing and level — the same raw data rendered differently for different diagnostic questions (maps to: same terminal state rendered differently for different agent tasks)

## Severity Calibration

- **P1**: Compressing away the diagnostically significant region

- **P2**: No progressive resolution path
  - When: Always sending maximum detail when low-res would suffice for most turns

When in doubt: describe the failure scenario. If it wakes someone at 3 AM, it is P0/P1. If it degrades quality over weeks, it is P2.
