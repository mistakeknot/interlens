## Task Context

A paradigm question for Elf Revel (Rust colony sim, WASM): can ASCII characters serve as geometric primitives in an isometric/top-down spatial scene? The game currently renders as a flat TUI at 120x40 chars with simple single-character glyphs and basic colors. The user wants to explore paradigms where characters ARE the geometry — textured surfaces, scaled sprites, SVG fills, character-as-polygon. The core tension: gaining spatial richness (depth, perspective, procedural art) while preserving the ASCII identity. This is not about incremental rendering improvements but about a fundamental shift in how the character grid is conceived — from text display to spatial medium.

## Review Approach

### 1. Channel independence

- Channel independence and the encoding budget: a khipu cord has ~7 independent encoding channels. A terminal character cell has at least: glyph identity (~200 useful Unicode chars), fg red (0-255), fg green (0-255), fg blue (0-255), bg red (0-255), bg green (0-255), bg blue (0-255), bold/dim/italic/underline attributes. That is potentially 10+ independent channels per cell. Does the rendering paradigm MAP spatial dimensions to encoding channels systematically (e.g., glyph = entity type, fg hue = terrain category, fg brightness = elevation, bg brightness = distance-from-camera, bg hue = biome, bold = player-relevant)? The khipu insight is that treating these as independent channels creates a combinatorial encoding space enormous enough to convey multi-dimensional spatial scenes from a 'low-resolution' grid. A 120x40 grid with 10 independent channels per cell is not 4,800 data points — it is 48,000.

### 2. Positional encoding

- Positional encoding and the decimal knot system: khipu use knot POSITION along the cord as a place-value system (ones position, tens position, hundreds position). Terminal cells similarly have POSITION within the grid as an encoding dimension. But the khipu insight is that position encodes information RELATIVE TO A REFERENCE STRUCTURE (the primary cord), not in absolute coordinates. Does the rendering paradigm define reference structures (terrain contour lines, building edges, entity positions) relative to which cell position carries spatial meaning? A cell at position (60, 20) means nothing in absolute terms but means 'three tiles northeast of the workshop' relative to a reference structure.

### 3. Subsidiary branching

- Subsidiary branching and hierarchical spatial data: khipu subsidiary cords create tree-like hierarchies from a linear medium. The character grid is two-dimensional but spatial data is often hierarchical: a biome contains terrain types, which contain flora, which contain individual entities. Does the rendering paradigm support HIERARCHICAL ENCODING where cells at one level of spatial hierarchy communicate differently than cells at another? A cell representing 'deep forest biome' at zoom-out should use a different channel assignment than a cell representing 'individual oak entity' at zoom-in — the same physical cell, different hierarchical encoding level.

### 4. The ~60

- The ~60-hue color palette as constraint, not limitation: khipu used approximately 60 distinct cord colors. Modern terminals support 16 million colors (24-bit). But the khipu tradition suggests that PERCEPTUALLY DISTINCT colors are the real constraint — humans can reliably distinguish perhaps 20-30 hues under typical viewing conditions. Does the design define a CURATED PALETTE of perceptually distinct color assignments rather than treating 24-bit color as a continuous space? A khipukamayuq using 60 carefully-distinguished colors encodes more reliably than one using 600 colors that blur into each other under varied lighting. What is the maximum number of hue assignments the player can reliably distinguish at terminal viewing distance?

### 5. Context

- Context-dependent interpretation and game mode as reading frame: the same khipu was read differently depending on whether the reader was conducting a census, calculating tribute, or recounting history — the physical encoding was fixed, but the interpretation frame changed. The same character cell could similarly convey different spatial information depending on the active game mode: in management mode, fg brightness = resource value; in exploration mode, fg brightness = elevation; in social mode, fg brightness = elf density. Does the paradigm design INTERPRETATION FRAMES that remap the meaning of encoding channels based on context, or does it fix a single encoding-to-meaning mapping?

### 6. The primary cord as structural spine: khipu pendant cords...

- The primary cord as structural spine: khipu pendant cords attach to a single primary cord that provides the organizational backbone. In the character grid, what is the 'primary cord' — the structural reference that organizes all other spatial encoding? It could be the terrain elevation contour, the colony boundary, the camera focus point, or the player's cursor position. Does the design identify a PRIMARY SPATIAL REFERENCE that organizes how all other encoding channels are interpreted? Without a primary cord, khipu pendants are just loose strings — without a spatial reference, encoded channels are just noise.

## Severity Calibration

- **P1**: The paradigm treats the character cell as a single encoding unit (one glyph + one color = one meaning) rather than exploiting the combinatorial space of 10+ independent channels per cell — leaving 90% of the encoding budget unspent while lamenting that 120x40 is insufficient resolution for spatial scenes
  - When: Rendering design assigns meaning to (glyph, color) pairs without systematically mapping independent spatial dimensions to independent cell properties (fg hue, fg brightness, bg hue, bg brightness, character shape, attributes)
- **P2**: 24-bit color is used as a continuous space (any color for any purpose) rather than as a curated palette of perceptually distinct assignments, causing encoding collisions where the player cannot reliably distinguish spatial information conveyed through similar hues
  - When: Color assignment uses arbitrary RGB values without a perceptual distinctness analysis ensuring that colors assigned to different spatial meanings are reliably distinguishable at terminal viewing distance and font size
- **P2**: Encoding channel assignments are fixed regardless of game mode or context, missing the khipu insight that the same physical encoding can convey different information under different interpretation frames — forcing every spatial dimension to have a permanent visual channel when they could time-share
  - When: No context-dependent reinterpretation of visual channels — brightness always means elevation, color always means terrain type — even when the current game mode would benefit from different channel assignments

When in doubt: describe the failure scenario. If it wakes someone at 3 AM, it is P0/P1. If it degrades quality over weeks, it is P2.
