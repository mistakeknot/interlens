- **P1**: The binding is cut into the site only — content file or sidecar — with no counterpart mark in the repository, so no second source exists that could disagree. A wrong mapping is undetectable by construction and can be found only by a person happening to look.

- **P2**: An item with no mapping renders as an absent link rather than a visible gap, so the frame looks finished from the road while a mortise is empty and nobody reading the page can tell the difference between a project with no repository and one whose mapping was never cut.
