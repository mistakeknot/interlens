## Task Context

ShadowBench proposes to score the values-under-pressure alignment dimension by tracking outcome distributions across pressure dimensions when cascading crises force tradeoffs. The means-ends reasoning dimension is scored by action type distributions and escalation patterns. These dimensions will be used for multi-model comparison and publication.

## Review Approach

### 1. Stakeholder

- Stakeholder-disaggregated outcome tracking: when the values dimension tracks 'humanitarian outcomes vs. stability tradeoffs', which populations are the unit of analysis — aggregate world-level metrics will mask cases where a model sacrifices a specific country's population to stabilize others, which is the morally relevant finding

### 2. Temporal scope

- Temporal scope and reversibility weighting: a model that accepts short-term humanitarian harm in exchange for long-term stability is making a different values choice than one that accepts irreversible harm — the scoring rubric must distinguish reversible sacrifices from irreversible ones and apply appropriate weights, otherwise temporal arbitrage is undetected

### 3. Counterfactual outcome baseline: 'did the model sacrifice...

- Counterfactual outcome baseline: 'did the model sacrifice humanitarian outcomes' requires a counterfactual — what would have happened under a neutral or baseline strategy? Without a counterfactual scenario track, the values score measures absolute outcomes rather than model-attributable decisions, and models inherit credit or blame for the starting scenario's trajectory

### 4. Procedural vs

- Procedural vs. outcome justice distinction: the means-ends reasoning dimension conflates whether the model used problematic means with whether it achieved good outcomes — some real governance frameworks treat procedural legitimacy as a constraint (rights-violations are wrong regardless of consequences) while others treat it as a factor — the rubric needs an explicit meta-ethical stance, and it needs to be the same meta-ethical stance across all scored scenarios

### 5. Cascading

- Cascading and indirect harm attribution: when a model deploys covert influence in Country A which destabilizes Country B's economy causing food insecurity in Country C, does the scoring rubric attribute the food insecurity to the model's original action? The causal chain length for attribution needs a defined cutoff, or the model's full causal responsibility is either systematically overcounted or undercounted

### 6. Multi

- Multi-model comparison fairness: if the scoring rubric uses absolute outcome thresholds (e.g., 'humanitarian score below X is a failure'), scenarios with different starting conditions will have systematically different baseline difficulty — the comparison across models must control for scenario difficulty or use model-relative rather than absolute scoring

## Severity Calibration

- **P0**: The values dimension uses aggregate world-level humanitarian metrics, allowing a model that maintains high global aggregate scores by sacrificing a single small country's population to never register as having made a problematic tradeoff — the benchmark publishes a 'humanitarian-first' alignment profile for a model that practiced concentrated harm
  - When: When humanitarian outcome tracking uses population-weighted global averages without per-country or per-group floor constraints
- **P1**: The values scoring rubric lacks a counterfactual baseline track — a model that inherits a scenario on a trajectory toward collapse and fails to arrest it is scored as having 'sacrificed humanitarian outcomes' even if no action could have prevented the collapse, contaminating the values profile with scenario-starting-condition artifacts
  - When: When the benchmark does not run an autonomous-baseline (no-model or random-action) version of each scenario to establish the counterfactual outcome distribution
- **P2**: The means-ends reasoning dimension scores covert action use without distinguishing between irreversible harms (covert destabilization causing civil war) and reversible ones (covert information operation that can be publicly disclosed) — the rubric treats all covert actions as equivalent, obscuring the moral gradient that practitioners would use to evaluate real governance decisions
  - When: When action type distributions are the sole means-ends signal and action consequence reversibility is not modeled in the scoring

When in doubt: describe the failure scenario. If it wakes someone at 3 AM, it is P0/P1. If it degrades quality over weeks, it is P2.

- A counterfactual baseline scenario track runs in parallel with every model evaluation: the same scenario with a null player (no actions taken) establishes the baseline trajectory, and the values score measures model-attributable deviation from that baseline
- The means-ends scoring rubric explicitly classifies actions by reversibility tier (reversible, costly-reversible, irreversible) and applies different weight multipliers, with the classification published in the benchmark methodology so it can be disputed and updated

## Decision Lens

Findings are ranked by attribution specificity: a values score that says a model 'prioritized stability over humanitarian outcomes' without specifying which populations experienced which harms over which time horizon is qualitatively different from the same score with full attribution — the former is a narrative label, the latter is a measurement. Secondary priority is temporal discounting: values that produce good short-term metrics at the cost of long-term irreversible harm require explicit temporal modeling in the scoring rubric. If you find an issue matching a P0/P1 scenario in Severity Calibration, label it P0 or P1 — do not downgrade to appear less alarming.
