## Severity Calibration

- **P0**: Operator runs `systemctl --user start hermes-amtiskaw.service` before the Discord-side session from the previous gateway has fully closed (local process exited but Discord gateway hasn't timed out the session yet). The new gateway's `hermes gateway run --replace` attempts to bind; Discord returns 'token in use'; service fails; Restart=on-failure retries; eventually succeeds once Discord releases — but in the meantime the unit cycles through failed state, and `--replace` is not helping because the conflict is remote, not local.
  - When: Plan does not wait for Discord-side session close. Recommend either (a) an explicit sleep of 30s between stop and start, or (b) a polling loop that tests a no-op Discord API call to confirm the bot appears offline from the platform side before starting.
- **P1**: An operator on a parallel SSH session runs `amtiskaw gateway run` manually during or after the migration, bypassing systemd. This second instance conflicts with the systemd-managed one for the bot token. The procedural prohibition 'only start via systemctl' is not mechanically enforced.
  - When: Wrapper script in step 12 does not check for an active systemd unit before exec'ing hermes. Recommend adding `systemctl --user is-active hermes-amtiskaw.service` check and refusing if active.
- **P2**: The unit file's existing ExecStart includes `--replace`, which is preserved in step 13. In normal operation this is harmless, but it means every restart (including Restart=on-failure loops) will attempt to steal the lock from any existing process. During a partial-network-failure scenario where the old gateway is alive but not reporting to systemd, a systemd-triggered restart would forcibly supplant it.
  - When: Plan preserves `--replace` in ExecStart without documenting its risk profile. Consider whether `--replace` is actually needed for the steady-state or only for recovery.

When in doubt: describe the failure scenario. If it wakes someone at 3 AM, it is P0/P1. If it degrades quality over weeks, it is P2.
