## Severity Calibration

- **P0**: Pilot pass/fail threshold for 'visible separation' is not numerically specified before the run
  - When: Any language like 'visibly different' or 'substantial separation' without a pre-committed quantitative criterion (e.g., non-overlapping 95% CIs on at least 2 dimensions with N=5) means the kill gate is unfalsifiable and the ritual is ceremonial — the single largest credibility risk.
- **P1**: Both models run on the same date/seed but with different prompt scaffolds because one lab's API requires different formatting
  - When: Any unexplained asymmetry between the two pilot runs (system prompt length differences, tool use differences, retry logic differences) invalidates the trial the way Maskelyne's critics invalidated H4's early trials.
- **P2**: Traces from a failed pilot are described as inputs to redesign but not as publishable artifacts
  - When: If the protocol only publishes traces conditional on pilot passing, selection bias is baked into the first public artifact. Commit to publishing pilot traces regardless of outcome.

When in doubt: describe the failure scenario. If it wakes someone at 3 AM, it is P0/P1. If it degrades quality over weeks, it is P2.
