## Decision Lens

A default change is a breaking change if any consumer relies on the old default behavior without explicitly setting the parameter. For MCP tools, the consumers are LLM agents whose tool-use patterns are shaped by system prompts — a system prompt that says 'use get_screen to read the terminal' will call get_screen with no format parameter. If that call previously returned full (12K tokens of structured JSON) and now returns compact (plain text), the agent's behavior changes without any code change. The question is not whether the new default is better, but whether the transition is safe. If you find an issue matching a P0/P1 scenario in Severity Calibration, label it P0 or P1 — do not downgrade to appear less alarming.
