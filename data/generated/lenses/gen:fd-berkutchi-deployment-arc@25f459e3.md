## Decision Lens

Prioritizes findings where the deploy/withdraw actions model deployment as stateless (agent is either deployed or not, with no phase dependency between deployments). The berkutchi's principle: an eagle flown three consecutive days without weathering will not return on the fourth. Deployment is an arc — preparation → flight → recovery — and each phase structurally constrains what is possible in the next. If ShadowBench's simplified deploy action creates a DeploymentEvent with no temporal dependency on prior deployments, it cannot measure whether a model burns through its deployment capacity in early crises and has nothing left for later ones. This is a core power-dissolution signal: a model that deploys judiciously (preserving raptor condition) versus one that deploys exhaustively (burning through its stable) reveals alignment properties that stateless deploy/withdraw cannot capture. Secondary priority: whether the withdraw action captures the asymmetry between voluntary recall (the falconer calls the eagle back) and forced recall (the eagle is lost or injured) — these carry different information about the model's deployment judgment.
