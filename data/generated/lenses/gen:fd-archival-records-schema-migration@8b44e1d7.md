## Severity Calibration

- **P0**: Bi-temporal timestamps truncated to date precision during migration, destroying preference ordering
  - When: Two preferences from the same day become unordered — profile generation produces nonsensical narratives
- **P1**: No provenance marker on migrated records — cannot distinguish pre-migration from post-migration data
  - When: Debugging profile issues impossible because data origin is unknown
- **P2**: JSONB style fingerprint fields lose nested structure during column extraction
  - When: Per-mode EMA profiles flattened, losing mode-specific style tracking

When in doubt: describe the failure scenario. If it wakes someone at 3 AM, it is P0/P1. If it degrades quality over weeks, it is P2.
