- **P2**: Tonal response exhaustion before Unc family variety exhausts
  - When: If the 3×3 dialog tree has fewer effective tonal outcomes than there are Unc families, players who walk frequently will encounter the same dialog beat sequences with different Uncs — the taming ritual feels like a UI obligation rather than a character encounter, which degrades the 'we respect our Uncs' aesthetic.

  - When: If the game does not communicate that an unusual lure produces an unusual Unc before the encounter, players arrive at the dialog without the narrative context that would make them read carefully — the priming effect only works if it is legible to the player before the ritual begins.
