## Severity Calibration

- **P0**: No error-state principle in a system whose founding metaphor is orientation before decision
  - When: OODA(RC) makes 'orient before decide' the system's core interaction loop, but when orientation data itself fails (no shade raster coverage, GPS denied, offline), the canon gives zero guidance on how the system should render its own failure to orient — the most philosophically important edge case in the entire canon (what does the interface do when it cannot orient the walker) is the one case none of the ten influences was spent on.
- **P1**: Motion named as a token category with zero specified values and no reduced-motion fallback
  - When: The token roadmap lists motion (holdover/tempo) as one of four token categories to build, but the canon that's supposed to constrain it gives no duration/easing values and never mentions `prefers-reduced-motion`; the first component author to build the reticle's tracking animation has to invent both the actual motion curve and the accessibility fallback from scratch, with no citation possible back to canon — violating the canon's own stated rule that 'every token cites a rule.'
- **P1**: Fixed-position 'system-as-garment' vocabulary has no responsive contract
  - When: ACRONYM's system-as-garment principle promises a walker 'learns the garment once and wears it everywhere,' but with no responsive rule, a small-viewport build either breaks the fixed-position promise (panels move/collapse, contradicting §6) or overflows/clips content (violating legibility) — and the canon offers no way to decide which failure is more acceptable.
