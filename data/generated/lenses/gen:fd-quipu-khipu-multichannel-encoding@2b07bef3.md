## Task Context

Quipu encoded complex administrative data in physical attributes of knotted cords. Terminal cells encode information in multiple visual attributes. Both are multichannel encoding problems.

## Review Approach

### 1. Independent semantic channels

- Independent semantic channels — quipu cords encode information in color, twist direction, knot type, and position independently. Terminal cells similarly have text, foreground color, background color, bold, and position as independent channels.

### 2. Hierarchical attachment

- Hierarchical attachment — pendant cords attach to a primary cord, subsidiaries attach to pendants. Maps to: terminal UI hierarchy (window → pane → region → line → span).

### 3. Color as categorical data

- Color as categorical data — quipu cord colors encode categories (e.g., types of goods), not decoration. Terminal colors encode categories (error, success, info) — encoding should preserve this as data.

### 4. Knot position as magnitude

- Knot position as magnitude — knot placement on a cord encodes decimal place value. Column position in a terminal encodes structural meaning (indentation = hierarchy).

### 5. Cord grouping as record structure

- Cord grouping as record structure — groups of cords form records. Groups of terminal lines form semantic blocks (a stack trace, a test result, a menu).

## Severity Calibration

- **P0**: Treating color as decorative and stripping it
  - When: Red (error) and green (success) outputs become indistinguishable — agent loses critical signal
- **P1**: Flattening hierarchical structure
  - When: Nested TUI panes encoded as flat text, losing the parent-child relationships that carry meaning

When in doubt: describe the failure scenario. If it wakes someone at 3 AM, it is P0/P1. If it degrades quality over weeks, it is P2.
