## Task Context

HaikuSelector wraps Skaffen's provider.Provider interface (defined in internal/provider/) to replace Python's subprocess call to 'claude -p --model haiku'. The selector constructs a prompt listing candidate lenses with 1-based indices and scale tags, calls the provider, parses the JSON array of selected indices, and maps them back to Lens structs. GLM 5.1 via z.ai is a planned alternative provider. The 15-second timeout and empty-list-on-error behavior are explicit requirements. Provider key configured via Z_AI_API_KEY env var.

## Severity Calibration

- **P0**: The LLM returns index 0 (zero-indexed) instead of 1-indexed due to a prompt ambiguity, and the Go code interprets this as off-by-one, selecting the wrong lens or panicking on index -1 after adjustment
  - When: Lens selection silently picks wrong lenses for every conversation turn
- **P1**: context.WithTimeout creates a child context for the provider call, but the provider's own transport ignores the context deadline and blocks for 45 seconds — the 15-second timeout in Select() is never enforced because the provider call is not context-aware
  - When: Agent loop stalls for 45 seconds on provider timeout, blocking the user's conversation
- **P2**: GLM 5.1 returns responses with a different JSON wrapping convention than Haiku (e.g., {"lenses": [1,2,3]} vs [1,2,3]), and the shared parser fails silently returning an empty list rather than adapting to the provider's output format
  - When: GLM provider always returns empty lens selection, making it appear non-functional without an error

When in doubt: describe the failure scenario. If it wakes someone at 3 AM, it is P0/P1. If it degrades quality over weeks, it is P2.
