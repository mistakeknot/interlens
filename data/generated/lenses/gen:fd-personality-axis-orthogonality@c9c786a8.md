## Task Context

The game already has a 4-axis aesthetic system driving taste and social dynamics. Adding 3 personality axes risks redundancy or noise.

## Review Approach

### 1. For covariance between proposed personality axes

- Check for covariance between proposed personality axes and existing aesthetic axes (e.g., social axis already drives company behavior — does extroversion duplicate this?)

### 2. Evaluate whether 3 axes produce sufficient combinatorial ...

- Evaluate whether 3 axes produce sufficient combinatorial variety (2^3=8 archetypes vs 3^3=27 gradient positions) for a colony of 8-20 elves

### 3. Assess whether each axis has at least 3 distinct gameplay...

- Assess whether each axis has at least 3 distinct gameplay effects that no other axis provides

### 4. For 'dead zones'

- Check for 'dead zones' — axis value ranges that produce no observable behavioral difference

### 5. Axis interactions (e

- Verify that axis interactions (e.g., proud + impulsive) create emergent behaviors beyond what either axis alone produces

## Severity Calibration

- **P1**: Extroversion axis overlaps so heavily with aesthetic social axis that adding it produces no new behavioral variety
  - When: Correlation between axes > 0.7 in expected behavioral outputs
- **P2**: Pride axis only matters during revel critique events, making it irrelevant 95% of gameplay
  - When: Axis affects fewer than 3 game systems
- **P3**: Middle values (0.4-0.6) on all axes produce indistinguishable behavior from the default
  - When: No gameplay effect for moderate personality values

When in doubt: describe the failure scenario. If it wakes someone at 3 AM, it is P0/P1. If it degrades quality over weeks, it is P2.
