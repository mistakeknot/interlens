## Task Context

Garden Salon governance brainstorm covering roles, directions, attribution primitives, and an evolutionary path from emergent usage to formal constitutions. 'Bring your own compute' model where contributors supply API keys.

## Review Approach

### 1. Role model completeness

- Role model completeness — does Owner/participant binary cover real-world scenarios like delegated moderators, read-only observers, or temporary elevated access for agents?

### 2. Governance capture risk

- Governance capture risk — can an Owner lock out co-owners, transfer ownership unilaterally, or install governance rules that make themselves irremovable?

### 3. Policy enforcement boundary

- Policy enforcement boundary — the design says gardens declare rules but the platform enforces them; are there gaps where declared rules can be circumvented at the platform layer?

### 4. Transition safety

- Transition safety — when a garden switches governance models (Solo → Cooperative), what happens to in-flight directions, existing attributions, and cached permissions?

### 5. Agent role ambiguity

- Agent role ambiguity — agents contribute compute but are they participants, tools of participants, or a third role class? The design is silent on agent identity in the permission model.

### 6. Audit trail coverage

- Audit trail coverage — are governance rule changes themselves attributed and versioned, or only contributions to content directions?

## Severity Calibration

- **P1**: Owner exits or becomes unreachable
  - When: The design has no succession mechanism. A sole-owner garden where the owner disappears creates an unresolvable governance deadlock — no one can merge directions, modify the constitution, or wind down the garden.

- **P1**: Agent acting under participant credentials
  - When: 'Bring your own compute' means agents run under a participant's API key. If an agent accrues attribution under a participant's identity, that participant gains voting weight or revenue share they did not personally contribute. The design does not distinguish human-authored vs agent-authored contributions under a shared identity.

- **P2**: Governance model migration with active directions
  - When: No migration path is specified. If a garden mid-direction switches from Solo to Cooperative, the authority to merge or abandon that direction is suddenly ambiguous.

When in doubt: describe the failure scenario. If it wakes someone at 3 AM, it is P0/P1. If it degrades quality over weeks, it is P2.
