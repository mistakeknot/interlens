## Severity Calibration

- **P0**: Swift app launches before FastAPI is ready and all API calls fail silently, leaving the app in a permanently broken state with no recovery path
  - When: If there is no startup readiness check and no retry/reconnect logic in the Swift HTTP client layer
- **P1**: Demucs separation is dispatched as a blocking HTTP call; it runs for 4 minutes, the URLSession times out, and the operation is abandoned while Python continues running in the background
  - When: If long-running operations are not modeled as async jobs with a job ID and status polling endpoint
- **P2**: A Claude Code skill and the Swift app both write to the same collisions/ project directory concurrently through FastAPI, producing partially-written mashup state
  - When: If the FastAPI layer has no per-project mutex or write serialization for filesystem operations

When in doubt: describe the failure scenario. If it wakes someone at 3 AM, it is P0/P1. If it degrades quality over weeks, it is P2.
