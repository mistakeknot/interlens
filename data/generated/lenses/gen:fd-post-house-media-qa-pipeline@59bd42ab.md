## Severity Calibration

- **P0**: ffmpeg compose runs against whatever is in shots/ without verifying each file was QA-approved.
  - When: A re-rendered shot written to shots/ under the same filename fails QA but is included in the final compose because the compose step does not check QA status.
- **P1**: CLIP drift threshold is a global hardcoded constant with no per-episode override.
  - When: An episode intentionally using surrealist imagery fails all shots at the default threshold, producing no usable output despite the shots being creatively correct.
- **P3**: QA results exist only as UI state in the Swift app, not written to disk.
  - When: Closing and reopening the app loses all QA history for the episode; user must re-run scoring from scratch.

When in doubt: describe the failure scenario. If it wakes someone at 3 AM, it is P0/P1. If it degrades quality over weeks, it is P2.
