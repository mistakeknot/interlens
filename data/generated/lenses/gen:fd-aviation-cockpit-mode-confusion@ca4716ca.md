## Severity Calibration

- **P0**: A player pressing Esc to close an overlay accidentally opens the pause menu instead, then clicks Quit because they expected Resume — the backtick/Esc split is the correct design but any regression here causes data loss
  - When: Input gating for Esc is not conditional on overlay state — Esc always opens pause menu even when an overlay is active, creating a mode confusion where the expected close action launches the quit path
- **P1**: OverlayState is not read by all input systems — Space pause, speed keys, or sim-control inputs fire through an active overlay because one system forgot the guard, breaking the centralized mode contract
  - When: Input gating implemented as per-system early-return guards rather than a centralized gate, leaving systems that were added after initial implementation unguarded
- **P2**: Player has no persistent on-screen indicator of whether overlays are open, so after alt-tabbing back they cannot determine current modal state without pressing keys to probe it
  - When: Mode annunciation is only implied by the overlay panel being visible, but the panel may be partially obscured by other UI elements in edge cases
