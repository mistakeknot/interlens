## Severity Calibration

- **P0**: SqliteSoulStore requires tokio runtime, elf-revel is sync
  - When: elf-revel uses pollster::block_on to wrap async store calls in its synchronous tick loop. If SqliteSoulStore internally uses sqlx with the tokio runtime, block_on over a sqlx future will panic at runtime ('no current thread runtime'). This is a deployment-time blocker that needs resolution before Phase 1 code starts: either elf-revel adopts tokio, or SqliteSoulStore uses sqlx's async-std feature, or elf-revel uses MemSoulStore for Phase 1 persistence.
- **P1**: Conflict error type without specified trigger mechanism
  - When: StoreError::Conflict is in the draft §6 error types but no SoulStore method accepts an expected SeqNo to trigger it. The error is logically dead code in the draft API. If §6 is locked before the optimistic concurrency mechanism is designed, a Phase 1 implementation will either never emit Conflict (making it useless) or emit it via an undocumented side-channel.
- **P2**: SoulMetadata.archetype consistency with Soul state
  - When: query_by_archetype returns Soul IDs based on archetype, but archetype in SoulMetadata is 'consumer-set via vocabulary' with no specified update trigger. If archetype is stale at query time, query_by_archetype returns wrong results. This is a silent correctness bug that only manifests in production, not in unit tests of individual methods.

When in doubt: describe the failure scenario. If it wakes someone at 3 AM, it is P0/P1. If it degrades quality over weeks, it is P2.

## Decision Lens

A storage trait is correct when every implementation can satisfy every method's contract. A storage trait is ergonomic when the hot-path operations are the cheapest to implement correctly. A storage trait is safe when the failure modes are explicit and recoverable. Traits that leave contract details to implementations produce implementations that silently disagree. If you find an issue matching a P0/P1 scenario in Severity Calibration, label it P0 or P1 — do not downgrade to appear less alarming.
