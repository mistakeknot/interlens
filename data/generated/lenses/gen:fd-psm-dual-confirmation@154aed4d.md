## Severity Calibration

- **P1**: Root-cause deduplication counts distinct themes (auth, perf) as two distinct root causes, but both signals fired because the bead corpus quality dropped across all themes simultaneously — the `>= 2` threshold fires BYPASS for what is effectively a single systemic event. The factory halts, the principal investigates, finds no theme-specific problem, resumes — and the factory halts again on the next check cycle for the same reason. The BYPASS trigger has become a persistent false halt under degraded-corpus conditions.
  - When: When root-cause deduplication uses theme tag presence rather than causal independence — two themes that share 80% of their bead population are not independent root causes but the deduplication logic cannot distinguish theme overlap from independent causal paths
- **P1**: The process crashes after writing the interspect halt record but before creating factory-paused.json — on restart, halt.IsHalted() returns false (file absent) and ockham check begins evaluating signals. reconstructHalt() is designed to run when the file is absent but the interspect record exists, but reconstructHalt() is only called from the reconfirmation path in check.go, not from the startup path — so a fresh ockham invocation after this crash proceeds without halt, silently voiding the halt.
  - When: When reconstructHalt() is called only on the check cycle that finds an existing interspect record but no file, and not on process startup — so the first check cycle after a crash-during-write proceeds without calling reconstructHalt()
- **P2**: The BYPASS threshold is configurable in anomaly.Config with no bounds validation — an operator sets `bypass_threshold: 1` intending to make BYPASS more sensitive, converting it from a multi-cause guard into a single-INFORM trip wire. The first INFORM signal on any theme now triggers a full factory halt, effectively making INFORM and BYPASS identical in behavior.
  - When: When the configurable threshold has no lower bound of 2 enforced at config load time, and the documentation does not warn that threshold=1 changes the fundamental semantics of the BYPASS tier from multi-cause detection to single-signal shutdown

When in doubt: describe the failure scenario. If it wakes someone at 3 AM, it is P0/P1. If it degrades quality over weeks, it is P2.
