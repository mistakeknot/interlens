## Review Approach

### Key Review Areas

- **Completion script correctness and coverage**: Check that shell completions exist for subcommands, flags, and value arguments (e.g., `--pack` could complete to available pack directories). Verify completions work for both the Go kernel CLI and Python agent pipeline CLI. Flag missing completions for frequently-used commands.

- **Stdin/stdout/stderr separation**: Verify that data output goes to stdout and status/error messages go to stderr across both CLI surfaces. Check that the kernel server logs don't pollute stdout when running in foreground mode. Flag any case where piping `agentmud-agents validate --json` would capture non-JSON output.

- **TTY detection and behavior adaptation**: Check that the SSH interface adapts to terminal capabilities (colors, width, UTF-8 support). Verify that agent connections (non-TTY) get raw JSON without ANSI codes. Flag cases where the player interface breaks on narrow terminals or non-color terminals.

- **Signal handling and graceful shutdown**: Verify that `agentmud serve` handles SIGINT/SIGTERM gracefully — saves player state, closes SSH connections, flushes telemetry. Check that the agent pipeline CLI handles interruption during long-running evaluations. Flag cases where Ctrl-C could leave state corrupted.

- **Config file discovery and precedence**: Check that configuration (kernel settings, agent pipeline config, pack paths) follows clear precedence: flags > env vars > config file > defaults. Verify that config file location is documented and discoverable. Flag magic paths or undocumented environment variables.
