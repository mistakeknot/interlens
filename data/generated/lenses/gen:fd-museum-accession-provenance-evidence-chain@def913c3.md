## Severity Calibration

- **P0**: Evidence chain broken at primitive boundary
  - When: An action recorded by one plugin (e.g., a session annotation in cass) cannot be linked back to the bead, agent identity, or trust event that produced it because there is no shared accession-grade identifier — the equivalent of a museum object whose conservation file cannot be matched to its accession record
- **P1**: Memory graduation overwrites prior state
  - When: When intermem promotes an auto-memory fact to AGENTS.md or interknow updates a pattern's authority weight, the prior state is overwritten rather than appended — equivalent to a conservator erasing previous treatment notes when applying new ones, destroying the chain that licenses current claims
- **P2**: Trust assertion without citation
  - When: Agent trust scores or routing decisions surface as confidence numbers without the underlying evidence trail accessible from the score — like attributing a painting to Rembrandt without the cited evidence, leaving the attribution unfalsifiable and unrevisable

When in doubt: describe the failure scenario. If it wakes someone at 3 AM, it is P0/P1. If it degrades quality over weeks, it is P2.
