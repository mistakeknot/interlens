## Severity Calibration

- **P1**: Required field is unbounded free prose with no length cap or structure
  - When: summary/rationale/lessons defined without max length, format hint, or schema validation
- **P1**: event_local_name is open-ended with no registry
  - When: Field accepts arbitrary strings with no enumeration mechanism for downstream tools
- **P2**: Annotation round-trip is undefined
  - When: Spec does not specify how Annotate-stage output is encoded back into next-cycle Proposal inputs
- **P3**: No defined null/missing-data convention
  - When: Spec does not state what an advisor emits when it cannot generate a confident rationale

When in doubt: describe the failure scenario. If it wakes someone at 3 AM, it is P0/P1. If it degrades quality over weeks, it is P2.
