## Severity Calibration

- **P0**: Distinguishing questions optimized for lens accuracy rather than user development
  - When: Questions designed to help the SYSTEM discriminate between lenses rather than to help the USER develop discriminative capacity — the calibration serves the algorithm, not the person
- **P1**: No progression tracking from recognition to autonomous deployment
  - When: System cannot distinguish a user who applies frameworks when prompted from one who spontaneously recognizes framework-relevant situations — like a Keju system that tests only recitation, never novel application
- **P2**: Formulaic application not detected
  - When: User learns to 'speak the language' of frameworks (applies them correctly by pattern) without genuine cognitive restructuring — the eight-legged essay failure where form replaces insight
