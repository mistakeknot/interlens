## Severity Calibration

- **P0**: Face detection runs on letterboxed/padded 1280-px input but the box is mapped back to 4K using only a uniform scale factor, ignoring the pad offset, so every face box is shifted by the letterbox margin — the destroyed region sits beside the real face and the face survives into the blurred_archive: a §8.5 zero-miss violation from pure misregistration.
  - When: P0 if the detection->source coordinate transform does not invert the exact resize+pad the model input used and there is no fixture asserting boxes land on the object; downgrade to P2 if a single tested letterbox-aware transform maps every model's boxes onto source pixels and a registration fixture proves it.
- **P1**: A face found inside a person crop is returned in crop-local coordinates and added to the person's top-left origin, but the person crop was itself taken from a resized detection frame, so the two offsets are in different coordinate spaces — the head-fallback and face boxes register block-to-block rather than to the master frame, leaving part of the head uncovered on profile/occluded cases.
  - When: P1 if crop-local detections are composited without a single frame-space transform shared by all cascade stages; downgrade to P3 if every cascade output is normalized to master frame coordinates before compositing and tested on a crop-offset case.
- **P2**: Redaction regions are drawn exactly to the detected box with dilation applied only spatially, not temporally, so on the pre/post extension frames (where there is no detection, only a held box) the box is not additionally dilated to cover the object's motion since the last detection — a fast subject drifts to the rim of its own held box between strides and a sliver of face shows for a few frames.
  - When: P2 if temporal hold reuses the last box geometry without motion-aware growth; downgrade to P3 if held/extended boxes are grown proportionally to elapsed frames and inter-stride displacement and this is tested on a fast-motion fixture.

When in doubt: describe the failure scenario. If it wakes someone at 3 AM, it is P0/P1. If it degrades quality over weeks, it is P2.
