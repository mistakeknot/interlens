Ranking five single-channel definitions then selects the best of a family that cannot see the actual failure, and the winner will look defensible and behave exactly like the current gate.

- **P2**: A definition is ranked well on discriminating yield while having no discordance rule, so it silently trusts whichever channel the implementation happens to read first. It behaves consistently on the sampled rows only because the sample under-represents surface-root inversions, and its extension will move the moment context resolution, logging, or prompt rendering changes — the same class of instability f-015 already observed on identical text.
