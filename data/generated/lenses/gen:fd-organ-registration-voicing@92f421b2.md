## Severity Calibration

- **P0**: Lens stacks are designed as sequential solo applications (apply lens A fully, then apply lens B fully) rather than as ensemble registrations where multiple lenses contribute simultaneously to a composite insight. This misses the primary value of multi-lens application.
  - When: The lens stack architecture processes lenses independently and concatenates their outputs, rather than creating a combined analytical frame where each lens modulates how the others are perceived — like playing organ stops together rather than sequentially.
- **P1**: No mechanism for context-dependent combination selection — the same lens pair is always combined the same way regardless of the user's cognitive style, the conversation's emotional register, or the problem's complexity domain.
  - When: Lens combination logic operates on problem features alone without incorporating the user's 'acoustic space' (how they process multiple frameworks) or the conversational 'liturgical moment' (whether this is exploration, crisis, reflection, or celebration).
- **P2**: Near-miss lens pairs identified in the cookoff are treated only as diagnostic hazards (confusable, therefore one must be excluded) rather than also as combination candidates (confusable because they illuminate adjacent aspects of the same deep structure).
  - When: The near-miss analysis produces only exclusion logic (when A, not B) without also producing combination logic (when both A and B reveal complementary facets of the same underlying dynamic).
