## Severity Calibration

- **P0**: Trust inheritance from shared packages
  - When: Hassease imports Skaffen's trust evaluator configured for autonomous operation — Skaffen auto-approves edits because it is a sovereign agent, and Hassease inherits this trust level instead of enforcing its own human-directed approval gates (like a relay merchant inheriting another's trade agreements and accidentally committing to terms beyond their authority)
- **P1**: Binary trust with no contextual graduation
  - When: The trust evaluator classifies tools as either auto-approve or require-approval with no file-path or content-based modulation — editing a README and editing a cryptographic key handler require the same approval ceremony (like treating a shipment of cotton and a shipment of imperial silk with identical security protocols)
- **P2**: No trust evidence accumulation
  - When: GLM has successfully edited 50 test files without error, but every 51st test file edit still requires full human approval — the system has no mechanism for building trust based on track record (like requiring full cargo inspection at every relay station regardless of the merchant's 20-year perfect record)

When in doubt: describe the failure scenario. If it wakes someone at 3 AM, it is P0/P1. If it degrades quality over weeks, it is P2.

Trust is not binary (trusted/untrusted) but graduated: this intermediary can repackage but not open, this one can inspect but not reroute, this one can hold but must forward within 3 days.
