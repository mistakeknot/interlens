  - When: Process dies after interspect write but before file write. reconstructHalt() will recreate the file on next check — BUT there is a window where IsHalted() returns false while halt-record.json says active. Any dispatch calls in that window violate INV-8.

## Decision Lens

Every multi-step write sequence is a potential crash window. The system must be safe in every partial-completion state — not just the happy path. The order of writes defines the failure mode, and the failure mode defines the recovery strategy. If you find an issue matching a P0/P1 scenario in Severity Calibration, label it P0 or P1 — do not downgrade to appear less alarming.
