## Severity Calibration

- **P1**: The ontology represents TaskState as a class hierarchy where Composing and Resting are subclasses of TaskState, allowing a query to return an entity that is simultaneously in both states — which the Rust enum type system prevents at runtime but the ontology cannot detect
  - When: No owl:disjointWith constraints between variant classes, leaving the ontology's validity model weaker than the code's type safety
- **P1**: An RDF reasoning library is included in the WASM binary for runtime ontology queries, adding 2-5MB to the bundle and making 60fps simulation ticks impossible
  - When: The design specifies runtime ontology queries from Rust code without specifying whether queries execute at compile time, build time, or at runtime
- **P2**: A Rust refactor renames a component struct (MoodModifier to MoodStack) and all ontology IRIs that embed the struct name become stale, breaking every SPARQL query that references that class
  - When: Ontology IRIs are derived from Rust type names without a stable alias or redirection layer
