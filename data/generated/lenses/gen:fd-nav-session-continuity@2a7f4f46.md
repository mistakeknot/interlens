## Severity Calibration

- **P1**: User returns after 24 hours and sees the same view as if they never left — no 'what's new' signal
  - When: No re-entry state briefing
- **P2**: Proposals from overnight agent work are mixed into the same list as old reviewed proposals — no recency signal

## Decision Lens

Re-entering a garden after an absence should feel like returning to a room — you should immediately see what changed while you were away. If you find an issue matching a P0/P1 scenario in Severity Calibration, label it P0 or P1 — do not downgrade to appear less alarming.

## Prioritization

- P0: Issues that block other work, cause data loss or corruption — drop everything
- P1: Issues required to exit the current quality gate
- P2: Issues that degrade quality or create maintenance burden
- P3: Improvements and polish — suggest but don't block on these
- For each P0/P1 finding, describe the concrete failure scenario: what breaks, under what conditions, and who is affected
- Always tie findings to specific files, functions, and line numbers
- Frame uncertain findings as questions, not assertions
