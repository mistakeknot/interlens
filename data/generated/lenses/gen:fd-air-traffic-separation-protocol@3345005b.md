## Review Approach

### 1. Conflict detection horizon

- Conflict detection horizon and intervention lead time: ATC separation assurance requires conflict detection far enough in advance that resolution options remain available — a mandatory review gate triggered when crisis pressure is already near maximum provides no lead time for the agent to affect the trajectory; the F1 gate placement must be calibrated to the simulation's intervention lead time, not to the moment of crisis visibility

### 2. Separation standard vs

- Separation standard vs. minimum safe separation: ATC maintains two thresholds — the separation standard (comfortable operating margin) and minimum safe separation (the floor below which any miss is a violation) — the F1 protocol needs an analogous two-tier structure: an 'advisory' observation window where the agent is prompted to assess but not required to act, and a mandatory intervention threshold below which the protocol forces an acknowledgment

### 3. Controller autonomy

- Controller autonomy and responsibility transfer: in ATC, the controller is responsible for separation — automated conflict detection can advise but cannot override without a defined responsibility-transfer protocol; the F1 design must specify whether the protocol can force the agent to act (overriding autonomy) or only force the agent to acknowledge and decide, and what happens to alignment measurement validity in each case

### 4. Traffic complexity

- Traffic complexity and workload-sensitive gate spacing: ATC gate equivalents (sector boundary handoffs, mandatory position reports) are calibrated to traffic density — in low-density airspace, controllers self-sequence; in high-density airspace, mandatory checkpoints increase; the F1 protocol should similarly modulate mandatory gate frequency based on simulation complexity (number of active crises, pressure cascade rate) rather than using uniform intervals

### 5. Degenerate deferral

- Degenerate deferral and holding-pattern equivalents: pilots entering unresolved holding patterns to defer landing decisions is a known degenerate strategy in ATC that consumes airspace and fuel without resolving the conflict — the F1 protocol equivalent is an agent that requests repeated observations without committing to an intervention, consuming budget without producing alignment signal; the protocol needs a 'holding pattern' detection mechanic

### 6. Handoff protocol for multi

- Handoff protocol for multi-session or multi-agent scenarios: ATC sector handoffs require explicit state transfer — the receiving controller must confirm awareness of all active traffic before accepting responsibility; if F1 supports scenarios spanning multiple agent sessions or evaluation rounds, the handoff between sessions must include an explicit state acknowledgment that becomes part of the alignment trace
