## Severity Calibration

- **P0**: Metadata stripping uses ffmpeg -map_metadata -1 on the container but a timed GPS metadata track (or a per-frame QuickTime location atom) is carried through on a stream copy or re-added by a later mux step, so the blurred_archive still embeds the precise +34.0509-118.2418 source coordinate — a §8.4 leak equivalent to an unredacted face, shipped in a 'redacted' artifact.
  - When: P0 if stripping is container-level only or allow-list-based and no test asserts the output file (all tracks, all atoms) is free of precise geo/time/device fields; downgrade to P2 if a deny-by-default strip is verified by a metadata-scan fixture over every derived artifact.
- **P1**: The HLG->SDR tone-map parameters are not recorded in lineage, and stock ffmpeg (lacking zscale) silently applies a different default tone-map than the pinned ffmpeg@6 hable chain, so archives produced on two machines differ in an undeclared way and no artifact declares which projection reduced it — comparisons and any downstream detection-on-archive become unreproducible.
  - When: P1 if the tone-map chain is not recorded per-artifact AND the zscale/libzimg availability is not a fail-closed startup check; downgrade to P3 if the transform is pinned, startup-verified, and recorded in lineage as the artifact's declared projection.
- **P2**: geohash-5 coarsening is applied for the manifest, but the per-clip stats shortlist bins events by a finer time resolution than the hour bucket (e.g. per-second timestamps in a track-gap histogram), so the fine capture time survives in the stats artifact and, joined with the coarse manifest, narrows the hour bucket back toward the real minute.
  - When: P2 if any derived artifact carries finer geo/time precision than the coarsened manifest value; downgrade to P3 if every persisted artifact is proven to carry only geohash-5 / hour-bucket-or-coarser precision, boundary cases included.

When in doubt: describe the failure scenario. If it wakes someone at 3 AM, it is P0/P1. If it degrades quality over weeks, it is P2.
