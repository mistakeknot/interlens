The game assigns elves to roles (Composer/Builder/Gatherer) and schedules communal events (revels). Personality should make role fulfillment feel individual, not just add separate social behaviors.

- Evaluate the 'host-guest' dynamic: tea ceremony assigns social roles (host/guest) that constrain behavior while revealing personality through HOW one fulfills the role. Do game roles (Composer/Gatherer/Builder) similarly reveal personality through execution style?

### 2. Whether personality enables 'ichi

- Check whether personality enables 'ichi-go ichi-e' (one time, one meeting) — each social encounter should be unrepeatable because the specific personality combination is unique. Does the system make encounters feel singular?

### 3. Assess the 'wabi' principle: imperfection as beauty

- Assess the 'wabi' principle: imperfection as beauty. Do extreme personality values create interesting imperfections rather than optimal or broken states?

### 4. Evaluate whether the system distinguishes 'omote' (public...

- Evaluate whether the system distinguishes 'omote' (public face) from 'ura' (inner reality) — elves might present differently in public (revel) vs private (workshop) based on personality

### 5. For 'ma' (negative space): tea ceremony uses silence

- Check for 'ma' (negative space): tea ceremony uses silence and pause as expressive elements. Does the personality system make INACTION meaningful — is an introvert's absence from a revel as significant as an extrovert's presence?

## Severity Calibration

- **P2**: Personality only affects what elves DO, never what they DON'T DO — introverts are just 'less social' rather than 'meaningfully absent'

- **P3**: All personality expression is uniform across contexts — an elf behaves the same whether at a revel (public) or alone in a workshop (private)
  - When: No context-dependent personality expression
