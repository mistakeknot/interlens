## Severity Calibration

- **P0**: A subsystem surfaces N Break receipts in the first sprint of Compound and then emits zero for the remaining window — the gate is satisfied, but the self-observation mechanism has effectively stopped operating, which CCM would flag as a control-silence anomaly
  - When: When the Break spec has no minimum distribution requirement and no zero-receipt floor that triggers a health alert
- **P1**: Interspect scores Break receipt severity but the spec does not establish whether Interspect is operating as an independent assurer or as a management-layer reviewer — this ambiguity determines whether Break receipts carry Tier-1 or Tier-2 evidential weight
  - When: When §7.1 does not specify the independence posture of Interspect relative to the subsystem surfacing Break receipts
- **P2**: The Break gate uses a fixed N regardless of Compound window length — a 30-day Compound window and a 180-day Compound window both require the same N receipts, making the receipt rate meaningless as a health signal

## Decision Lens

Prioritize findings where the Break design would allow a subsystem to pass a gate without demonstrating that its self-observation mechanisms are operating continuously. In CCM, a control that fires zero exceptions for a month is suspicious — either the population is clean or the control has gone silent. If Break receipts can hit ≥N without triggering an alert when the rate drops to zero after passage, the gate is not a health signal; it is a one-time compliance artifact. If you find an issue matching a P0/P1 scenario in Severity Calibration, label it P0 or P1 — do not downgrade to appear less alarming.
