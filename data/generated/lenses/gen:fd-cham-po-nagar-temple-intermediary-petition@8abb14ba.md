- How does the system handle the 'translation fidelity' problem — when Hassease summarizes a proposed edit for Signal approval, does the summary faithfully represent what will actually happen, or can the translation lose critical details?

- Is there an urgency triage mechanism — can the system distinguish between edits that need immediate human attention (touching auth code) vs. those that can queue until the next review batch?

- Does the intermediary architecture preserve the petitioner's intent through the proxy chain — when GLM proposes an edit, Hassease translates it for Signal, human approves, and Hassease executes, does the executed action match what the human thought they were approving?

### 6. How does the system handle the 'closed temple' problem

- How does the system handle the 'closed temple' problem — when the human is unavailable for approval, does work queue gracefully or does the entire pipeline stall?

## Severity Calibration

- **P0**: Translation infidelity in approval summary
  - When: Hassease's Signal message says 'edit auth.py to add token refresh' but the actual proposed edit also removes an existing validation check — human approves based on incomplete translation, and the intermediary executes something the petitioner did not actually sanction
- **P1**: No approval batching — notification fatigue
  - When: Every single file edit sends a separate Signal message, even when 15 test file edits are part of one logical change — builder either rubber-stamps everything (defeating the approval purpose) or abandons the flow (like a worshipper who stops coming to temple because every minor request requires a full ritual)
- **P2**: No unavailability handling
  - When: When the builder doesn't respond to Signal for 30 minutes, the daemon has no queue/timeout/fallback — approved reads continue but the edit pipeline freezes entirely, with no way to batch pending approvals for when the builder returns

When in doubt: describe the failure scenario. If it wakes someone at 3 AM, it is P0/P1. If it degrades quality over weeks, it is P2.
