## Task Context

A paradigm question for Elf Revel (Rust colony sim, WASM): can ASCII characters serve as geometric primitives in an isometric/top-down spatial scene? The game currently renders as a flat TUI at 120x40 chars with simple single-character glyphs and basic colors. The user wants to explore paradigms where characters ARE the geometry — textured surfaces, scaled sprites, SVG fills, character-as-polygon. The core tension: gaining spatial richness (depth, perspective, procedural art) while preserving the ASCII identity. This is not about incremental rendering improvements but about a fundamental shift in how the character grid is conceived — from text display to spatial medium.

## Review Approach

### 1. Dot

- Dot-grid inversion — characters as scaffold, relationships as geometry: kolam's deepest structural insight is that the dot grid is invisible infrastructure while the lines between dots are the visible art. Current ASCII rendering places content IN cells. The kolam paradigm suggests placing content BETWEEN cells — using box-drawing characters, line-drawing Unicode, or color boundaries between adjacent cells to create visible geometry that the character grid merely scaffolds. Does the rendering paradigm consider a mode where the PRIMARY visual content is the borders and connections between cells rather than the cell contents themselves? This is the most radical paradigm shift available: the grid becomes topology, not canvas.

### 2. Single

- Single-line continuity and path-based rendering: many kolam are single continuous lines — one gesture creates the entire figure. This maps to a rendering approach where spatial features (rivers, roads, walls, terrain boundaries) are rendered as CONTINUOUS PATHS through the grid rather than as collections of individually-colored cells. A river rendered as a continuous path of ~ characters with directional flow has more spatial coherence than a river rendered as isolated blue cells. Does the design treat linear features as PATHS with continuity, direction, and connection rather than as independent cell colorings?

### 3. Generative constraint

- Generative constraint — same grid, infinite patterns: the same kolam dot grid generates hundreds of distinct patterns depending on the weaving path. This maps directly to the ASCII-as-geometry question: a 120x40 grid is a GENERATIVE CONSTRAINT that can produce infinite spatial scenes depending on how color, brightness, and character assignment navigate the grid. Does the paradigm treat the grid dimensions as a generative constraint (what spatial forms can emerge from 120x40?) rather than as a resolution limit (120x40 is too coarse for real geometry)? The kolam tradition proves that a 15x15 dot grid IS geometry — it generates geometric and figurative forms of extraordinary complexity.

### 4. Pulli count as complexity metric

- Pulli count as complexity metric — grid density as design space: kolam practitioners measure pattern complexity by dot count, not by line intricacy. A 5x5 grid enables simple symmetric patterns; a 15x15 grid enables figurative forms with internal detail. The 120x40 character grid is analogous to a 120x40 pulli field — an extraordinarily dense scaffold by kolam standards. Does the design recognize that 120x40 is actually an ENORMOUS generative space? A kolam master would see 4,800 intersection points and infinite path topologies. The paradigm should explore what geometric forms are possible in a grid this dense, not lament that it is too coarse for 'real' graphics.

### 5. Sikku (interlocking loops)

- Sikku (interlocking loops) and layered spatial systems: sikku kolam creates multiple interlocking loops that share grid points but never cross — a topological layering where multiple independent figures coexist on the same grid. This maps to the rendering challenge of multiple spatial layers (terrain, flora, entities, weather) sharing the same character grid. Does the design treat the character grid as a shared scaffold that multiple visual layers navigate independently, creating composite imagery through interlocking rather than through z-order occlusion? Kolam's interlocking loops show that multiple figures can share a grid without any figure 'hiding' another.

### 6. Threshold liminality

- Threshold liminality — the kolam as spatial boundary marker: kolam are drawn on thresholds (doorsteps, entrances) — liminal spaces between inside and outside. The kolam marks a transition in spatial character. The character grid rendering a colony sim similarly marks transitions: between terrain types, between owned and wild land, between safe and dangerous areas. Does the design give special rendering treatment to BOUNDARIES and TRANSITIONS between spatial zones, recognizing that boundaries carry more spatial information than interiors? The kolam tradition suggests that boundary rendering should receive disproportionate design attention.

## Severity Calibration

- **P1**: The paradigm treats the 120x40 grid exclusively as a canvas where each cell contains content, never exploring the possibility that inter-cell relationships (borders, connections, flow paths) could constitute the primary visual geometry — missing the most powerful available paradigm shift for making ASCII feel spatial
  - When: All rendering concepts place visual content INSIDE character cells (glyph selection, cell coloring) with no exploration of how cell BOUNDARIES, box-drawing connections, or color-flow between adjacent cells could create visible geometry on a different topological layer
- **P2**: Linear spatial features (rivers, roads, walls, terrain edges) are rendered as collections of independently-colored cells rather than as continuous paths with directional flow and connection logic, producing fragmented rather than coherent spatial forms
  - When: River, road, and boundary rendering assigns characters/colors to individual cells without a path-continuity system that tracks how linear features connect through the grid
- **P2**: The 120x40 grid is treated as a resolution limit rather than a generative constraint — design discussion focuses on what CANNOT be shown at this resolution rather than what spatial forms CAN emerge from a 4,800-point scaffold with full color and Unicode
  - When: Design framing consistently uses deficit language ('only 120x40,' 'too coarse for X') rather than generative language ('4,800 cells enables Y') and focuses on pixel-equivalent resolution rather than on grid topology

When in doubt: describe the failure scenario. If it wakes someone at 3 AM, it is P0/P1. If it degrades quality over weeks, it is P2.
