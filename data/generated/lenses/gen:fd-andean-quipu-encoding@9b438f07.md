## Task Context

Reviewing a first-principles civilizational taxonomy (8 domains, 40 sub-systems, 221 countries) for a simulation. The taxonomy must encode civilizational state with enough dimensionality to capture qualitative distinctions, not just quantitative levels.

## Review Approach

### 1. Encoding dimensionality: A quipu cord carries information...

- Encoding dimensionality: A quipu cord carries information simultaneously in color, material, ply direction, knot type, knot position, pendant group, and subsidiary structure. Does each of the 40 sub-systems encode state across multiple simultaneous dimensions, or is each sub-system a single scalar? 'Credit creation' represented as a single number vs. 'credit creation' represented as (volume, velocity, concentration, maturity-profile, currency-denomination, collateral-quality) are fundamentally different information architectures.

### 2. Structural encoding (arrangement IS meaning): In quipu

- Structural encoding (arrangement IS meaning): In quipu, the position of a cord relative to its neighbors carries meaning — a red cord between two blue cords means something different from a red cord between two white cords. Does the taxonomy capture structural relationships between sub-systems as information-bearing — or does it treat each sub-system's state as independent of its neighbors?

### 3. Subsidiarity

- Subsidiarity and hierarchy: Quipu use subsidiary cords (small cords attached to pendant cords) to encode hierarchical detail — provincial totals on main cords, district breakdowns on subsidiaries. Does the taxonomy support hierarchical detail within sub-systems — country-level totals with regional, ethnic, or class breakdowns as 'subsidiary cords'?

### 4. Decoding without the encoder: Approximately 70% of surviv...

- Decoding without the encoder: Approximately 70% of surviving quipu cannot be fully interpreted because the tacit knowledge of the quipucamayocs who created them has been lost. Does the taxonomy's state representation carry enough structural context to be interpretable without external documentation — or does interpreting a simulation snapshot require knowing unstated assumptions about what each parameter means in context?

### 5. Cross

- Cross-domain summary cords: Quipu often include summary cords that aggregate information across groups. Does the taxonomy specify cross-domain summary metrics that aggregate state across multiple domains into composite indicators — or does each domain report independently, requiring the observer to perform the aggregation?

### 6. Narrative encoding: Recent research suggests some quipu e...

- Narrative encoding: Recent research suggests some quipu encoded narrative information (not just quantities) through pattern sequences. Does the taxonomy support encoding qualitative state — not just 'how much' but 'what kind' of governance, economy, or social fabric a country has? A scalar value for 'state capacity' loses the qualitative distinction between authoritarian capacity and democratic capacity.

## Severity Calibration

- **P0**: Each of the 40 sub-systems is represented as a single scalar parameter (e.g., 'credit_creation: 0.73'), losing all structural dimensionality — a quipu reduced to a single knot per cord. The taxonomy cannot distinguish between qualitatively different states that produce the same scalar value (high credit creation via healthy lending vs. via asset bubble)
  - When: Sub-system state is scalar rather than multi-dimensional
- **P1**: The taxonomy has no mechanism for cross-domain composite indicators — each domain reports its state independently, requiring external aggregation to understand system-level health. A quipu without summary cords requires the reader to mentally sum each column.
  - When: No cross-domain summary metrics or composite indicators are specified
- **P2**: The taxonomy's state representation requires external documentation to interpret — a simulation snapshot of 'Domain 2, Sub-system 1, Parameter 3 = 0.65' is meaningless without knowing the encoding schema, and the schema is not embedded in the representation itself
  - When: State representation is not self-documenting — interpretation requires external tacit knowledge

When in doubt: describe the failure scenario. If it wakes someone at 3 AM, it is P0/P1. If it degrades quality over weeks, it is P2.

## Decision Lens

Prioritizes findings where the taxonomy's state representation under-utilizes its encoding dimensions or creates ambiguity that requires external context to resolve. A quipu uses 7+ simultaneous encoding channels (cord color, material, ply direction, knot type, knot position, pendant grouping, subsidiary attachment) — each channel carries independent information and together they form a multi-dimensional address space. If the taxonomy's 8 domains and 40 sub-systems use only scalar parameters (single numbers) to represent each state, they are using cord position only and ignoring color, knot type, grouping, and subsidiary structure. The state space will be impoverished. Secondary priority: whether the taxonomy creates encoding ambiguity — situations where the same state representation could mean different things depending on context not captured in the representation itself. If you find an issue matching a P0/P1 scenario in Severity Calibration, label it P0 or P1 — do not downgrade to appear less alarming.
