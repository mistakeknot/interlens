## Review Approach

### 1. Channel count vs. channel capacity

- Channel count vs. channel capacity: 24-bit color + character shape + character density + animation state = 4 simultaneous encoding channels — cognitive research shows players can reliably decode 2-3 channels in a glanceable UI

### 2. Redundant encoding

- Redundant encoding: infographic best practice is to encode the most critical information on 2 channels simultaneously (color + shape, not color alone) — ASCII rendering should decide which game state information gets redundant encoding and which gets only one channel

### 3. Progressive disclosure hierarchy

- Progressive disclosure hierarchy: the 120x40 grid has roughly 4800 cells — what is visible at the overview level, what requires zoom/inspect, what only appears in the sixel/kitty protocol detail view? This must be designed, not emergent

### 4. Noise floor

- Noise floor: video-to-ASCII conversion of complex scenes produces high-entropy character output that reads as texture, not information — the noise floor of each rendering technique must be understood before mixing

### 5. Glanceability under stress

- Glanceability under stress: colony sims create decision stress — the rendering enrichment must remain parseable when 20 things are happening simultaneously, not just in a calm single-entity demo
