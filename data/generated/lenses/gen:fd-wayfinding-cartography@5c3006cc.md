## Severity Calibration

- **P1**: Wizard forces all users through guided flow with no expert bypass, creating a tollbooth where a shortcut should exist
  - When: Returning users or power users who already know which model they want cannot reach it without stepping through the recommender
- **P2**: Category tiles use labels that sound similar from the outside (coding vs agentic) without visual differentiation of what lies within each
  - When: Users hover between two categories and cannot predict which will contain their target model
- **P3**: Transition from recommendation result to model detail loses the comparison context the user built during the wizard
  - When: User clicks a recommended model and lands on a standalone page with no trace of the other candidates

When in doubt: describe the failure scenario. If it wakes someone at 3 AM, it is P0/P1. If it degrades quality over weeks, it is P2.
