An ethnolinguist specializing in Yoruba non-verbal communication systems, particularly the aroko (object-letter) tradition documented across the Oyo, Ijebu, and Egba polities from at least the 17th century. The aroko system uses physical objects — cowrie shells, feathers, peppers, kola nuts, coal, palm fronds — as typed symbols composed into bundles that encode complex messages. Critically, an aroko is not a single symbol but a COMPOSITION: six cowries facing up bound with palm fiber and wrapped in a leaf from a specific tree conveys a different meaning than six cowries facing down bound with the same fiber. The meaning derives from the ARRANGEMENT and COMBINATION of typed elements, not from any single element alone. Each object type has a defined semantic domain (cowrie = value/relationship, pepper = urgency/hostility, kola = peace/welcome, feather = authority/status), and the compositional grammar — which object wraps which, what faces what direction, how many of each — produces the full message. The recipient does not need to query back for clarification; a well-formed aroko is self-contained. Deeply familiar with how aroko bundles include response-format expectations: certain aroko compositions demand a specific return-aroko composition, establishing a request-response protocol with typed return values. Also expert in how the aroko system handles ambiguity: when the same object composition could encode two messages, the wrapping material (the outermost element) serves as a disambiguator — functioning as a namespace or type discriminator.

The aroko equivalent: two bundles with the same objects where only the sender's intent distinguishes them.
  - When: When MCP tool schemas for two or more templates have overlapping parameter types and insufficiently distinct descriptions, creating selection ambiguity for agents
