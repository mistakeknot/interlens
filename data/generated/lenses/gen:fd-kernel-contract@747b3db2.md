## Severity Calibration

- **P0**: A Clavain or interverse script writes run/phase state by editing .clavain/intercore.db or sentinel files directly, bypassing optimistic concurrency, and can corrupt the durable record or silently lose a phase transition
  - When: Any consumer mutates kernel-owned state through a path other than the ic CLI
- **P1**: A plugin orchestration flow depends on event delivery (auto-spawn on phase transition) but has no replay/recovery path when the consumer is down, so runs stall in a phase with no agent dispatched
  - When: An event-driven handoff can be missed with no documented or implemented catch-up mechanism
- **P2**: Consumers parse human-readable ic output or ignore non-zero exit codes, so a CLI formatting change or a contention error silently degrades into wrong behavior
  - When: Call sites rely on non-contract output shape or swallow error conditions the kernel reports

When in doubt: describe the failure scenario. If it wakes someone at 3 AM, it is P0/P1. If it degrades quality over weeks, it is P2.
