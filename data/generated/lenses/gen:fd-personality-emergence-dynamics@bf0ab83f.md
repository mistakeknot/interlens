## Severity Calibration

- **P1**: Extroverted + proud elves are strictly better (higher satisfaction, more prestige) creating an optimal personality that makes other combinations feel like penalties
  - When: Any personality combination has >20% higher expected satisfaction
- **P2**: Personality only modifies existing systems by small percentages without creating qualitatively new behaviors
  - When: All personality effects are linear modifiers to existing formulas

When in doubt: describe the failure scenario. If it wakes someone at 3 AM, it is P0/P1. If it degrades quality over weeks, it is P2.
