## Severity Calibration

- **P0**: PRD or schema permits any Notion write path back to beads
  - When: Inverts the stationary reference without a documented frame transition; future agents will dead-reckon from a moving chart
- **P1**: last_synced is exposed but no convention specifies what staleness means for a decision
  - When: Etak-island bearing is reported in degrees but the navigator was not told the calibration; the number is unactionable
- **P2**: Different bridge scripts use different defaults (one --dry-run, one --apply) without a shared rationale
  - When: Inconsistent frame discipline across the fleet; one canoe drifts while others hold position

When in doubt: describe the failure scenario. If it wakes someone at 3 AM, it is P0/P1. If it degrades quality over weeks, it is P2.
