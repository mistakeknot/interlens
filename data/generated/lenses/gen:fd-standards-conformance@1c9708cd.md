## Severity Calibration

- **P1**: No normative/informative distinction
  - When: The entire spec uses 'should' uniformly, making it impossible to determine which requirements are binding vs advisory — a conformant and a non-conformant implementation would look identical against the spec
- **P2**: Conformance class undefined
  - When: The spec defines minimum conditions for earning the name but does not define what a compliant vs non-compliant implementation is, leaving no way to assess conformance without author judgment
- **P2**: Version coupling absent
  - When: The spec does not state which version of interflux the inherited contract is drawn from, meaning upstream revisions may silently invalidate declared conformance without any detection mechanism

When in doubt: describe the failure scenario. If it wakes someone at 3 AM, it is P0/P1. If it degrades quality over weeks, it is P2.
