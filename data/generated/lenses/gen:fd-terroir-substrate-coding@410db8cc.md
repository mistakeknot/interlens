## Task Context

Politics-coding axis review for Unc Rancher (bead `solwend-2ug`). The brief proposes an 8-value posture-grain enum for a procedural character-generation politics axis. The terroir lens asks: is each value *appellation-quality* (naming a real and reproducible substrate-condition) or is it *brand-wine quality* (naming a marketing identity that looks like a substrate but is really a taste-cluster label with no terroir beneath it)?

## Review Approach

### 1. The appellation test: does each value name a substrate condition or a taste identity?

- In wine, "Burgundy" names a place-substrate that reliably produces a kind of wine — not the wine's taste itself. Does each politics-coding value name a substrate condition (something upstream that reliably produces a political flavor) or does it name the flavor itself? Values that name flavors are brittle (they collapse when the same substrate produces different flavors in different eras). Values that name substrate conditions are durable across the class × region × media-era cross-product.
- Apply this specifically to: `true-believer`, `oppositional`, `single-issue-coded` — these are the values most likely to be naming flavors, not substrate conditions.

### 2. The terroir-vs-brand split: which values have authentic substrate and which are marketing constructs?

- The Burgundy appellation system distinguishes *premier cru* (specific parcel: real, reproducible, measurable) from *Bourgogne générique* (region-brand). Does the politics axis have values that are specific-parcel-quality (they name a real intersection in the class × region × media-era matrix that reliably produces a recognizable type) versus brand-quality (they are recognizable but not reproducible — the same "substrate" can produce wildly different political flavors)?
- The brief raises this concern about `classical-liberal-edgelord` in the original sketch — but is `oppositional` a better version of the same problem (brand-wine named by the label, not the soil)?

### 3. The minerality problem: substrate-taste that only appears when conditions are right

- Terroir produces *minerality* — a taste quality that only appears when the wine is made correctly from the right substrate. Some political stances only appear as recognizable types when a specific set of substrate conditions (media-era + class + region) converge. The values that require a specific substrate convergence should probably be modeled as emergent cross-products, not primary axis values. Flag any value in the 8-value draft that is really a cross-product phenomenon masquerading as a primary axis value.

### 4. The vintage problem: values that are era-specific and will not generalize

- Some terroirs produce era-specific wines. `Reagan-Democrat` is the prototype of an era-specific value that the brief correctly rejects. Does any value in the 8-value draft have hidden era-specificity? `disaffected` in particular may be a 2010s–2020s phenomenon rather than a perennial substrate condition.

### 5. The natural wine question: values that resist legibility by design

- Natural wine resists appellation and score-based legibility — it is deliberately substrate-driven and resists taste-normalization. Does the Unc Rancher politics axis have room for political types that resist legible classification (the explicitly post-political, the locally-encoded-but-nationally-incoherent)? The `vocationally-absorbed` value may be in this category — it is a natural-wine politics that resists the classification system by refusing to enter it.

### 6. Cross-cultural terroir failure: values that assume French-wine geography

- The original French appellation system failed to generalize to New World wines not because New World wines were bad but because the appellation categories were French-specific. Does the 8-value politics draft assume US-specific political substrate geography? Would a British-Labour or Irish-Republican or Quebec-sovereignty Unc read as any of the 8 values, or would they require a different appellation entirely?
