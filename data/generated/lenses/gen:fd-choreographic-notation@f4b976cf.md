## Task Context

Dance notation compresses rich 3D spatial-temporal information into compact 2D symbolic marks. Terminal state is simpler (2D grid + attributes) but faces the same compression challenge.

## Review Approach

### 1. Level of body representation

- Level of body representation — Labanotation distinguishes 'support', 'gesture', and 'body' columns. Terminal state could have 'structure', 'content', and 'emphasis' channels.

### 2. Direction symbols vs. position coordinates

- Direction symbols vs. position coordinates — notation uses 8 directional symbols instead of x,y coordinates. Terminal content could use relative positioning.

### 3. Effort notation

- Effort notation — Laban's effort graph encodes quality-of-movement in 4 dimensions. Maps to: encoding emphasis quality (dim, bold, blinking, inverse).

### 4. Motif notation

- Motif notation — simplified notation for choreographic intent vs. full notation for exact reproduction. Maps to: summary vs. full-fidelity terminal state.

## Severity Calibration

- **P1**: No motif-level summary available
  - When: Agent must parse full terminal state when a high-level summary of changes would suffice
- **P2**: Temporal and spatial mixed in one encoding
  - When: Can't separate 'what changed' from 'where everything is'

When in doubt: describe the failure scenario. If it wakes someone at 3 AM, it is P0/P1. If it degrades quality over weeks, it is P2.
