## Task Context

Garden Salon features live salon sessions where humans and agents collaborate in real-time using Yjs for presence and CRDT state. Agents are first-class participants. The default is optimistic — agent changes land immediately. Participants may join and leave sessions dynamically.

## Review Approach

### 1. Orphaned directions on disconnect

- When a salon session ends or a participant disconnects, what happens to their active directions and in-flight agent actions — is there a 'handoff' protocol that transfers authority, or do orphaned directions enter an undefined state?

### 2. Single controlling authority per direction

- Is there always a clear 'controlling authority' for each direction at any given moment — ATC requires exactly one controller per sector; does Garden Salon's governance model prevent two participants from simultaneously exercising merge authority on the same direction?

### 3. Transfer of control window

- How does the system handle the 'transfer of control' window — the period between when one participant relinquishes authority and another accepts it — and is this window modeled or assumed to be instantaneous?

### 4. Agent authority persistence on human disconnect

- When an agent is executing autonomously and the human who authorized it leaves the salon, does the agent's authority persist, expire, or transfer — and is this behavior governance-configurable?

### 5. Session handoff record

- Is there a 'flight strip' equivalent — a persistent record of what each participant was working on, what they handed off, and what they left incomplete — that survives session boundaries?

### 6. Mid-session join situational awareness

- Does the presence system (Yjs awareness) provide sufficient information for participants joining mid-session to understand the current state of authority and active work, or do they enter blind?

## Severity Calibration

- **P1**: Agent continues executing after authorizing human disconnects
  - When: If a human starts an agent on a direction, then loses connectivity, and the agent continues making changes with no one to review — the optimistic-by-default model means those changes land in the shared state with no human in the loop, potentially for an extended period

- **P1**: Dual authority on direction merge
  - When: If the governance model allows multiple participants to merge a direction and two attempt it concurrently, the system must either serialize (creating a race) or reject one (creating a failed expectation) — without an explicit protocol for this, the behavior is implementation-dependent

- **P2**: Session join with no situational awareness
  - When: A participant joins a salon mid-session with active directions, running agents, and recent merges — if the presence/awareness layer only shows who is online and not what they are doing or what state each direction is in, the new participant cannot safely take any action without first manually reviewing everything

When in doubt: describe the failure scenario. If it wakes someone at 3 AM, it is P0/P1. If it degrades quality over weeks, it is P2.
