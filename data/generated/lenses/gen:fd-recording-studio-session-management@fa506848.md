## Severity Calibration

- **P0**: Stem separation writes outputs to a fixed path in collisions/ that is overwritten on each run with no versioning.
  - When: User re-runs Demucs with different parameters; original stems are lost; the prior mashup candidate can no longer be reconstructed.
- **P1**: The mashup project format records only the final output path, not the full parameter chain (source BPM, target BPM, model used, stem mix ratios).
  - When: A mashup that sounded good cannot be reproduced six months later because the parameters are not recorded — only the output file survives, and its provenance is opaque.
- **P2**: A/B comparison candidates are ephemeral — closing the music surface loses the candidate list.
  - When: User must re-run discovery and re-generate candidates for a mashup project they want to revisit; past work is not recoverable from the project file.

When in doubt: describe the failure scenario. If it wakes someone at 3 AM, it is P0/P1. If it degrades quality over weeks, it is P2.
