## Task Context

Auraken is a cognitive augmentation agent with 291 conceptual lenses that operates as a systems-thinking consultant, not a chatbot. It uses an OODARC conversation model (Observe-Orient-Decide-Act-Reflect) and builds deep personal context over months. A 12-model Forge stress test identified near-miss lens pairs (lenses that match on surface features but address different underlying dynamics), distinguishing questions, lens stacks (sequential multi-lens application), and contraindications. The design challenge is operationalizing these calibration findings as improvements to the consultant interaction model — making the agent a better consultant, not adding chatbot features. ## Severity Calibration

- **P0**: Lens stacks treat sequential lens application as additive analysis (each lens adds a new perspective to a stable problem) rather than transformative intervention (each lens changes the problem space that subsequent lenses operate on). This misunderstands the fundamental nature of cognitive reframing.
  - When: The lens stack design allows arbitrary ordering and treats the sequence as a portfolio of perspectives rather than a developmental arc where each step creates preconditions for the next.
- **P1**: No concept of 'working temperature' — the conversation model has no way to assess the user's current cognitive-emotional readiness for a particular intervention, applying reframes based on analytical relevance alone.
  - When: The OODARC Decide phase selects lenses based on problem-situation fit without incorporating signals about the user's current state of engagement, emotional activation, or capacity to receive a challenging reframe.
- **P2**: No annealing period between lens applications — the conversation model applies multiple reframes in rapid succession without allowing the user to integrate each one, risking cognitive 'stress fractures' where insights fragment rather than cohere.
  - When: Lens stacks are applied within a single conversation turn or rapid sequence without pacing mechanisms that allow the user to sit with each reframe before the next is offered.

When in doubt: describe the failure scenario. If it wakes someone at 3 AM, it is P0/P1. If it degrades quality over weeks, it is P2.

- The design includes explicit pacing between lens applications — 'annealing periods' where the user integrates one reframe before the next is offered
- The irreversibility of cognitive reframes is acknowledged in the design — the system tracks that a user who has received a particular reframe now operates in a transformed problem space
