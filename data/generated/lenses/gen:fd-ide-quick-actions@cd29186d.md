## Severity Calibration

- **P1**: Two slash commands have nearly identical names but different scopes (e.g., /clavain:review vs /code-review:code-review vs /pr-review-toolkit:review-pr) — user can't tell which to invoke
  - When: User picks wrong command, wastes a turn, retries with another
- **P2**: The user types a verb (`/recall`) but must remember the plugin namespace prefix
  - When: Discoverability collapses; user falls back to `/help` or `cass search`
- **P2**: Frequently-used commands (per cass tool analytics) require more keystrokes than rarely-used ones
  - When: Keyboard-first ergonomics inverted vs usage frequency

When in doubt: describe the failure scenario. If it wakes someone at 3 AM, it is P0/P1. If it degrades quality over weeks, it is P2.
