## Task Context

Review the Garden Salon encryption design brainstorm through the lens of diplomatic communications security — does the architecture protect content as if the relay network were controlled by an adversary?

## Review Approach

### 1. Does the architecture treat the server as a hostile relay

- Does the architecture treat the server as a hostile relay — analogous to a diplomatic cable crossing foreign territory — or does it assume any server component is trusted?

### 2. Is key distribution solved without a trusted courier

- Is key distribution solved without a trusted courier — can participants establish shared keys without the server ever seeing key material, like a Diffie-Hellman key agreement?

### 3. Is there compartmentalization

- Is there compartmentalization — can different content within a garden have different classification levels (e.g., CRDT state vs governance rationale vs AI interaction logs)?

### 4. Does the 'Blind Relay' (Option 3) account for traffic ana...

- Does the 'Blind Relay' (Option 3) account for traffic analysis — even if the server can't read content, can it infer activity patterns, collaboration relationships, or content size from the encrypted traffic?

### 5. Is there a 'diplomatic pouch' mechanism for the AI proxy

- Is there a 'diplomatic pouch' mechanism for the AI proxy — a way to send content to the LLM provider that preserves confidentiality guarantees, or is the AI proxy explicitly treated as a declassification boundary?

### 6. How does the system handle key compromise

- How does the system handle key compromise — if one participant's key is compromised, what is the blast radius, and is there forward secrecy?

## Severity Calibration

- **P0**: The key agreement protocol requires the server to relay key material in a way that lets the server derive the shared secret — the 'courier' can read the 'pouch'
  - When: Server can derive encryption keys during key exchange
- **P1**: No forward secrecy — compromising one session key lets an attacker decrypt all past garden content, not just the current session
  - When: Missing forward secrecy in key derivation
- **P2**: The server can infer which participants are actively collaborating and when, even without reading content — metadata leakage reveals collaboration patterns
  - When: Traffic analysis reveals participation metadata

When in doubt: describe the failure scenario. If it wakes someone at 3 AM, it is P0/P1. If it degrades quality over weeks, it is P2.
