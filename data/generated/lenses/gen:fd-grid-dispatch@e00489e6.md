- **P1**: A domain enters CONSTRAIN state and Ockham freezes it — but two other domains that depend on artifacts produced by the frozen domain continue executing, generating beads that will eventually fail when they attempt to integrate with the frozen domain's output, creating a cascade of failed beads in adjacent domains that each individually appear healthy

- **P2**: An agent oscillates between supervised and shadow tiers across three consecutive bead executions because the pleasure signal threshold is set just above the agent's typical performance level — each promotion triggers a supervised execution that is slightly below threshold, triggering demotion, which resets the promotion window, creating a promotion-demotion oscillation that prevents the agent from building the sustained track record needed for autonomous operation
  - When: When the autonomy ratchet lacks hysteresis — promotion and demotion use the same threshold rather than a promotion threshold higher than the demotion threshold — so performance near the boundary creates oscillation
