## Review Approach

### 1. Pre-emption capability and vulnerability symmetry: 5G QoS defines both

- Pre-emption capability and vulnerability symmetry: 5G QoS defines both pre-emption capability (can this flow bump a lower-priority one?) and pre-emption vulnerability (can this flow be bumped?) — check whether cross-model dispatch only models downward adjustment (score 1 → downgrade) without defining an upgrade path when a high-score expansion agent would benefit from a tier bump, and whether the absence of a pre-emption capability concept means high-score agents passively retain their tier rather than actively reclaiming capacity from low-score agents that were dispatched earlier

### 2. Bearer admission control vs. binary budget gate: telecom networks perform

- Bearer admission control vs. binary budget gate: telecom networks perform admission control that checks whether admitting a new GBR bearer would push total committed GBR above the air interface capacity — check whether the budget pressure computation (remaining_budget / sum(stage2_estimates)) correctly accounts for the already-committed model tiers of Stage 1 agents and other expansion agents in the same batch, or whether it computes pressure against a gross budget estimate that ignores concurrent committed costs

### 3. Non-GBR flow handling under congestion: non-GBR bearers have no floor guarantee

- Non-GBR flow handling under congestion: non-GBR bearers have no floor guarantee and can be starved to zero under heavy GBR load — verify that the _routing_downgrade function correctly floors at haiku rather than producing an undefined or empty model name when called on an already-minimum-tier agent, and that the logic handles the edge case where the safety floor is at the agent's already-assigned model (haiku checker with min_model absent) without attempting a no-op downgrade that wastes a function call

### 4. Bearer modification vs. new bearer establishment: in 5G

- Bearer modification vs. new bearer establishment: in 5G, changing a flow's QoS class mid-session requires a bearer modification procedure distinct from initial establishment — assess whether the design correctly separates the initial routing_resolve_agents call (bearer establishment) from the routing_adjust_expansion_tier call (bearer modification), and whether the per-agent model override mechanism cleanly supersedes the earlier resolved value or requires defensive handling for agents that may have cached their originally resolved model

### 5. Reflective QoS marking and role-based self-declaration: in some 5G deployments

- Reflective QoS marking and role-based self-declaration: in some 5G deployments, the UE marks its own traffic with DSCP values that the network honors if they fall within the contracted class — assess whether expansion agents that have explicit role-based model_tier assignments in agent-roles.yaml should have those assignments respected as self-declarations that bound how far the tier adjustment can downgrade them, rather than treating all agents as equally eligible for arbitrary downgrade regardless of their role configuration

### 6. Packet delay budget and latency sensitivity of tier assignment: 5QI classes

- Packet delay budget and latency sensitivity of tier assignment: 5QI classes carry a packet delay budget that determines which flows get preferential scheduling under congestion — assess whether expansion agents with score=3 that represent time-sensitive arbitration findings (P0 adjacent) should hold a higher-quality tier with the same non-negotiability as delay-sensitive GBR bearers, rather than simply keeping their default tier which may itself have been resolved conservatively before Stage 1 findings were available

- **P1**: The budget pressure computation divides remaining_budget by sum(stage2_estimates) using the pre-adjustment model tier costs, but _routing_downgrade has already been called for three agents in the same batch — the actual sum(stage2_estimates) is lower than the estimate used in the denominator, making budget_pressure appear lower than it is and preventing the high-pressure downgrade from firing for remaining agents that should have been downgraded
