## Severity Calibration

- **P0**: The clip-replace fallback path (delete_clip + import_midi_file) deletes the original clip, then import_midi_file fails due to a disk/API error. The track now has no clip, the session is in a corrupted state, and realize_ensemble fails fast — but the clip is permanently lost from the track.
  - When: The PRD does not require writing the mutated MIDI to a temp file before calling delete_clip, nor does it specify whether the original clip is backed up before deletion.
- **P1**: Pass 4 inserts gamak grace notes (alternating ±1 semitone) on the same MIDI channel as a note that received a non-zero pitch bend in Pass 3. The grace notes play at the bent pitch, not at the intended ±1 semitone — the gamak oscillation is microtonally displaced for the entire ornament duration.
  - When: The PRD does not specify whether ornament grace notes inherit the parent note's pitch bend, or whether Pass 4 is required to emit a bend=0 context around grace note events.
- **P2**: The 'straight-12-tet' render includes reset controller events at tick 0 that the raw MIDI does not have. A consumer comparing raw vs straight-12-tet MIDI at the byte level finds differences and incorrectly concludes the patch is not an identity — flagging a false positive in automated diff checks.
  - When: The PRD does not clarify that 'straight-12-tet' is a logical identity (no musical mutation) rather than a byte-identical identity. The reset events are always emitted.

When in doubt: describe the failure scenario. If it wakes someone at 3 AM, it is P0/P1. If it degrades quality over weeks, it is P2.
