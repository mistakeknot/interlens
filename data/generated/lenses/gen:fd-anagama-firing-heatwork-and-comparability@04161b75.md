Nothing therefore requires the nine confirmatory trajectories to be fired as one campaign. If arms are run mixture-by-mixture as capacity frees up — the natural way rented compute is actually consumed — the oral-heavy arm is fired in a different week, possibly a different node class, driver and framework build, than the literate-heavy arm. The preregistered primary contrast then carries an environment term of unknown sign and magnitude that no equality in the charter constrains, and no post-hoc analysis can separate it, because there is no condition fired in both weeks.
  - When: P0 because it attacks the single preregistered primary contrast and is unrecoverable after the fact. Downgrade to P1 if the charter is read as implicitly requiring one campaign and the fix is only to say so plus interleave arms; downgrade to P2 if a frozen stack digest and interleaving requirement already exist elsewhere in the program's engineering standard.
- **P1**: The variance pilot exists to 'estimate seed and item variance and freeze the confirmatory power calculation', and the confirmatory run is a later, larger, separately authorized campaign at a venue chosen in the interim. No condition is specified to appear in both campaigns. If the confirmatory campaign's run-to-run dispersion is larger than the pilot's — a different node class, a different degree of kernel nondeterminism, a different checkpoint cadence — the study is underpowered by an amount it cannot detect, and the power gate will already have passed. The charter treats power as a property of item, source-group and seed counts, which are all quantities carried forward on paper, rather than of the dispersion the confirmatory kiln actually produces.
  - When: P1 rather than P0 because one anchor condition run in both campaigns, plus a declared rule to re-open the power calculation if its dispersion moves, repairs it without changing arms, seeds or budget. Escalate to P0 if the pilot and confirmatory campaigns are already expected to use different venues and the power calculation is stated as frozen once.
- **P2**: The token-dose trend is derived from 'identical intermediate checkpoints, allowing a token-dose trend analysis without launching additional trajectories', while the confirmatory endpoint is read at 'the same ... stopping point' of a shared learning-rate schedule. An intermediate checkpoint under a live, undecayed learning rate and a decayed final checkpoint are not one object measured at two doses; a monotone trend across them is partly the schedule annealing, and the dose-response claim written into the Scientific question rides on it.
  - When: P2 because the dose trend is explicitly secondary to the preregistered primary contrast and the repair is a stated interpretive limitation plus, if wanted, a matched short-decay probe. Escalate to P1 if dose-responsiveness is retained as a confirmatory rather than exploratory claim.
