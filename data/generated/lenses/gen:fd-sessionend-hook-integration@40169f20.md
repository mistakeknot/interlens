## Severity Calibration

- **P0**: The hook script is written as 'clavain-cli calibrate-gate-tiers --auto' with a relative path to clavain-cli that resolves correctly in interactive shells but not in Claude Code's hook execution environment (different PATH); the hook silently fails with 'command not found' on every session end, logging nothing visible to the operator
  - When: Calibration never runs automatically; the 10-sprint no-touch streak is never achieved; the failure is invisible unless the operator explicitly checks hook execution logs
- **P1**: Two SessionEnd hooks run concurrently (rapid reconnect scenario) without file locking; both read cursor_ts = T1, both drain records from T1 to T2, both write v2 with cursor_ts = T2; the second write wins and overwrites the first's calibration output, but this is benign; however, if the first write sets cursor_ts = T3 (longer drain) and the second write sets cursor_ts = T2 (shorter drain due to race), the second write rolls back the cursor, causing records T2-T3 to be re-processed on the next SessionEnd
  - When: Calibration double-counts records in the T2-T3 range; FNR may be inflated enough to trigger an incorrect tier promotion during a high-throughput sprint
- **P2**: The SessionEnd hook runs calibrate-gate-tiers without a shell timeout wrapper; a large backlog in gate-outcomes.jsonl (e.g., 10,000 records from a long sprint) causes the drain to take 45 seconds; Claude Code's hook runner kills the process after its timeout, leaving v2 in the tmp-rename intermediate state
  - When: Next session start finds a .tmp file alongside v2 from a previous incomplete write; the calibration reader must detect and handle this stale tmp file or it may read the incomplete v2

## Decision Lens
