## Severity Calibration

- **P0**: The redaction pipeline composites the cosmetic Gaussian blur as a separate branch and, on a config or code path where pixel-destruction is skipped or fails silently, the archive is encoded from the blur-only frames and still marked derived_redacted — a reversible (95.9%-re-identifiable per the cited Revelio work) archive ships as if irreversibly redacted.
  - When: P0 if the destruction and cosmetic passes are separable such that any path can emit blur-only-and-labelled-redacted; downgrade to P2 only if destruction is structurally upstream of and inseparable from the cosmetic pass and a test asserts the released bytes are unrecoverable.
- **P1**: Redaction processes frames streaming to the encoder; a crash or model-load failure partway through a clip leaves an archive containing early destroyed frames and later raw frames, and the manifest/lineage is written as derived_redacted for the produced file — a permanently half-cleaned artifact with an unredacted tide-line is treated as a finished redacted output.
  - When: P1 if artifact-finalization (rename to final path + derived_redacted lineage) can occur without a completeness gate proving every frame was redacted end-to-end; downgrade to P3 if finalization is atomic on whole-clip completion and any partial run yields no derived_redacted artifact.
- **P2**: There is no trial-patch test that actually attempts to recover a face from a destroyed region; 'blur is cosmetic, destruction is the boundary' is enforced only by choosing a fill method in code, so a future change to the destruction primitive (e.g. a strong pixelate that looks destroyed) could silently reintroduce reversibility with no test catching it.
  - When: P2 if the irreversibility property has no recovery-attempt fixture guarding it; downgrade to P3 if a golden test asserts a recovery/re-identification attempt against destroyed regions fails and runs on every change to the primitive.

When in doubt: describe the failure scenario. If it wakes someone at 3 AM, it is P0/P1. If it degrades quality over weeks, it is P2.
