- **P1**: Go uses avg_words < 5 instead of avg_words <= 5 for the 'very short' threshold — a user with exactly 5 avg_words falls into the 'concise' bucket in Go but 'very short' in Python, producing different mirroring instructions for users at the boundary

- **P1**: Go's hedge special case uses hedge["i feel like"] > 0 (value check) rather than _, ok := hedge["i feel like"]; ok (presence check) — Python's 'in hedge' tests key presence, so a key with count 0 (which cannot normally occur but might in a deserialized fingerprint with integer 0 from JSON null coercion) would trigger the instruction in Python but not Go

  - When: Prompt engineering tooling that extracts style sections by header string fails to find the Go-generated section, silently omitting style mirroring from analysis

When in doubt: describe the failure scenario. If it wakes someone at 3 AM, it is P0/P1. If it degrades quality over weeks, it is P2.
