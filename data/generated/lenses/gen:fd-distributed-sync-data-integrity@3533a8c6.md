  - When: The prune sweep on a machine runs against a locally-pulled registry state that has not yet caught up to the harvest commit covering that repo.
- **P0**: Two machines harvest the same repo in the same window with no described lock or turn-taking; zklw's merge-by-content-hash has no described tie-break or conflict log for the case where the two jsonl files disagree about the same lens's hash due to a non-deterministic normalization step — this is exactly the split-brain the task asks to prioritize, and the design does not name a resolution.
  - When: Concurrent harvest runs on Mac and zklw target overlapping repos before either commits.

  - When: Both local and zklw Ollama are unreachable during a query, and the caller has no way to detect the fallback tier.
