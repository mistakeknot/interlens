- **P1**: No vocabulary version validation on replay
  - When: Phase 1 acceptance criterion requires replay to produce identical state to live computation, but the test suite validates only happy-path (vocabulary unchanged); no test validates behavior when vocabulary version at record time differs from version at replay time

  - When: Two apps independently register vocabularies with VocabularyId('characters'); no canonical URL or namespace prevents collision; a federation import that touches both apps merges incompatible facet spaces under the same ID
