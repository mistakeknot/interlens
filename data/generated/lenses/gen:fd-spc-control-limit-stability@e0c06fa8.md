## Severity Calibration

- **P1**: A theme with exactly 10 outcomes in the 30-day window has 4 false negatives, giving estimated FNR = 0.40 > 0.30, triggering promotion to hard tier. The true FNR is 0.20 but the small-sample estimate exceeded the threshold by chance. The hard tier rejects legitimate work for several sprints before the next recalibration window accumulates enough data to reverse the promotion.
  - When: When the n >= 10 guard is treated as sufficient sample size for a 0.30 FNR threshold rather than as a coarse anti-noise floor — a Bayesian credible interval or bootstrap confidence check on the FNR estimate would prevent acting on high-variance small samples
- **P1**: The rolling window spans a sprint boundary where a tier promotion was applied mid-window. The post-promotion gate behavior is stricter, so the second half of the window contains more true positives (the harder gate catches more real issues). The FPR computed over the full window underestimates the post-promotion FPR because it is diluted by the permissive pre-promotion period. The next calibration cycle finds FPR acceptable and leaves the tier unchanged, even though the actual post-promotion FPR has climbed above threshold.
  - When: When the window does not track tier-change boundaries and outcomes collected under different gate configurations are pooled without weighting or segmentation
- **P2**: A low-volume theme (safety) accumulates zero gate fires in a 30-day window. The algorithm computes FPR = 0/0 = NaN or 0.0, which does not exceed the promotion threshold. The tier stays soft. But the zero-volume period reflects the absence of safety-relevant work, not a well-calibrated soft gate — on resumption of safety work, the first several real positives will not have the benefit of a hard tier even though the gate has never been validated on this theme.
  - When: When zero-outcome windows are treated as confirmed-good calibration rather than as censored observations with unknown quality

When in doubt: describe the failure scenario. If it wakes someone at 3 AM, it is P0/P1. If it degrades quality over weeks, it is P2.
