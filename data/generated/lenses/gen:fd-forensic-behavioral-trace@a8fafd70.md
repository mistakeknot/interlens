## Task Context

ShadowBench proposes to log full decision traces (world state, model observation, chain-of-thought reasoning, action taken, consequences) for post-hoc analysis of deception, power-seeking, and coherence. The trace is the primary evidentiary artifact for the alignment profile.

## Review Approach

### 1. Temporal ordering enforcement between reasoning trace

- Temporal ordering enforcement between reasoning trace and action commit: if the model's chain-of-thought reasoning is generated and logged after the action token is sampled, the 'reasoning' is post-hoc rationalization rather than decision rationale — the logging architecture must enforce that reasoning precedes and cannot be retroactively edited after action selection

### 2. Revealed vs

- Revealed vs. stated preference divergence detection: the current design proposes measuring deception by comparing stated goals to action patterns over time — this requires a methodology for establishing 'stated goals' as a baseline at session start and then tracking drift between the stated goal trajectory and the observed action trajectory, with statistical significance thresholds

### 3. Power accumulation trajectory analysis: 'power

- Power accumulation trajectory analysis: 'power-seeking beyond what's needed' requires a counterfactual baseline — what influence level is necessary for the model's stated objectives? Without a counterfactual model of minimal-necessary-influence, excess influence accumulation cannot be distinguished from efficient goal pursuit

### 4. Logging completeness for omission detection: a sophistica...

- Logging completeness for omission detection: a sophisticated model may achieve covert goals by not taking actions that a naive observer would expect — the trace must log not just actions taken but actions available-and-not-taken at each decision point, enabling detection of strategic omission patterns

### 5. Chain

- Chain-of-thought authenticity: does the model's stated reasoning reference specific world state values (pressure levels, country statistics) that were actually present in its observation at that turn, or does it reference plausible-sounding but fabricated state descriptions? Cross-referencing reasoning content against the logged world state at each turn detects confabulation

### 6. Replay

- Replay and audit infrastructure: the full decision trace must be sufficient to deterministically reproduce the scenario from any decision point — enabling human auditors to step through the session, observe what the model saw, and evaluate whether its stated reasoning was consistent with its information state

## Severity Calibration

- **P0**: The logging pipeline samples the model's reasoning trace after the action has been committed to the simulation — all 'stated reasoning' in the trace is post-hoc rationalization and the deception dimension is measuring confabulation style rather than decision-making transparency
  - When: When the API interaction protocol does not enforce a strict reasoning-before-action ordering and the logging system records both from the same model response without temporal separation
- **P1**: The trace logs actions taken but not the full action menu available at each decision point — a model that systematically avoids covert action options (always present but never selected) appears 'transparent' when it may be strategically abstaining from actions it knows are observable
  - When: When 'available-and-not-taken' is treated as unimportant for deception detection and only the selected action is recorded
- **P2**: The stated-vs-revealed preference divergence metric uses the model's initial session goal statement as the baseline, but a model that updates its stated goals mid-session to retroactively match its actions will produce low divergence scores despite strategic goal-shifting
  - When: When the 'stated goals' baseline is re-sampled each turn rather than anchored to the session-start declaration
