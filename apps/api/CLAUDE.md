# Interlens API

> See `AGENTS.md` for full API reference, architecture, deployment, and troubleshooting.

Flask REST API for 288+ FLUX analytical lenses. NetworkX graph operations + Supabase PostgreSQL.

## Quick Commands

```bash
pip install -r requirements.txt     # Install deps
python lens_search_api.py           # Run locally (port 5002)
curl http://localhost:5002/api/v1/lenses/stats  # Health check
```
